# Advanced Python Practice: Strings and Loops

**Total questions: 10**

These questions are more challenging than basic string exercises. They focus on problem-solving, nested loops, indexing, slicing, and careful use of conditions.

## Rules

- Use only strings, variables, conditions, and `for` / `while` loops.
- Do not use lists, tuples, sets, dictionaries, or other data structures.
- Do not use built-in methods that directly solve the main task, unless a question allows them.
- Build the result step by step.

## Q1. Count overlapping occurrences of a substring

### Description

You are given two strings, `S` and `P`. Count how many times `P` occurs inside `S`.

Occurrences may overlap.

For example, in `aaaa`, the substring `aa` occurs at these positions:
- Index 0
- Index 1
- Index 2

Therefore, the answer is `3`.

Do not use the `count()` method.

### Input

- First line: string `S`
- Second line: string `P`

### Constraints

- `1 <= length of S <= 100`
- `1 <= length of P <= length of S`

### Output

Print the number of occurrences of `P` in `S`.

### Sample Input 1

```text
aaaa
aa
```

### Sample Output 1

```text
3
```

### Sample Input 2

```text
banana
ana
```

### Sample Output 2

```text
2
```

## Q2. Compress consecutive characters

### Description

You are given a string `S`. Compress consecutive repeated characters by writing the character followed by the number of times it appears consecutively.

For example:

- `aaabbc` becomes `a3b2c1`
- `xxxxzz` becomes `x4z2`

Only consecutive repetitions should be grouped. The same character appearing again later must be treated as a separate group.

Do not use dictionaries or lists.

### Input

A single string `S`.

### Constraints

- `1 <= length of S <= 100`
- The string contains lowercase English letters.

### Output

Print the compressed string.

### Sample Input 1

```text
aaabbc
```

### Sample Output 1

```text
a3b2c1
```

### Sample Input 2

```text
abca
```

### Sample Output 2

```text
a1b1c1a1
```

## Q4. Check whether two strings are anagrams

### Description

You are given two lowercase strings, `S1` and `S2`.

Two strings are anagrams if they contain exactly the same characters with the same frequencies, but the characters may appear in a different order.

For example, `listen` and `silent` are anagrams.

Print `yes` if the strings are anagrams. Otherwise, print `no`.

Do not sort the strings. Do not use lists, dictionaries, or other data structures.

### Input

- First line: string `S1`
- Second line: string `S2`

### Constraints

- `1 <= length of S1, length of S2 <= 100`
- Both strings contain lowercase English letters.

### Output

Print `yes` or `no`.

### Sample Input 1

```text
listen
silent
```

### Sample Output 1

```text
yes
```

### Sample Input 2

```text
hello
world
```

### Sample Output 2

```text
no
```

## Q5. Reverse every word in a sentence

### Description

You are given a sentence containing lowercase English words separated by single spaces.

Reverse each word individually, but keep the order of the words unchanged.

For example:

`python is fun`

becomes:

`nohtyp si nuf`

Do not use `split()` or a list.

### Input

A single sentence.

### Constraints

- `1 <= length of sentence <= 100`
- Words are separated by exactly one space.
- The sentence contains lowercase English letters and spaces.

### Output

Print the sentence with every word reversed.

### Sample Input 1

```text
python is fun
```

### Sample Output 1

```text
nohtyp si nuf
```

### Sample Input 2

```text
hello world
```

### Sample Output 2

```text
olleh dlrow
```

## Q7. Check whether a string is a rotation of another string

### Description

You are given two strings, `S1` and `S2`.

Check whether `S2` can be obtained by rotating `S1`.

A rotation moves characters from one end of the string to the other without changing their relative order.

For example:

- `abcd` rotated left by 2 positions becomes `cdab`.
- Therefore, `abcd` and `cdab` are rotations.

Print `yes` if `S2` is a rotation of `S1`. Otherwise, print `no`.

Do not use lists or other data structures.

### Input

- First line: string `S1`
- Second line: string `S2`

### Constraints

- `1 <= length of S1, length of S2 <= 100`
- Both strings contain lowercase English letters.

### Output

Print `yes` or `no`.

### Sample Input 1

```text
abcd
cdab
```

### Sample Output 1

```text
yes
```

### Sample Input 2

```text
abcd
acbd
```

### Sample Output 2

```text
no
```

## Q9. Check whether one string is a subsequence of another

### Description

You are given two strings, `S` and `P`.

Check whether all characters of `P` appear in `S` in the same order.

The characters do not need to be next to each other.

For example:

- `abcde` contains `ace` as a subsequence.
- `abcde` does not contain `aec` as a subsequence because the order is different.

Print `yes` if `P` is a subsequence of `S`. Otherwise, print `no`.

### Input

- Second line: string `P`

### Constraints

- `1 <= length of S <= 100`
- `1 <= length of P <= 100`
- Both strings contain lowercase English letters.

### Output

Print `yes` or `no`.

### Sample Input 1

```text
abcde
ace
```

### Sample Output 1

```text
yes
```

### Sample Input 2

```text
abcde
aec
```

### Sample Output 2

## Q10. Find the longest palindromic substring

### Description

You are given a string `S`. Find the length of the longest substring that is a palindrome.

A substring must contain consecutive characters from the original string.

For example, in `babad`, the longest palindromic substrings are `bab` and `aba`. Their length is `3`.

Print only the length of the longest palindromic substring.

Do not use lists, dictionaries, or other data structures.

### Input

A single lowercase string `S`.

### Constraints

- `1 <= length of S <= 100`
- The string contains lowercase English letters.

### Output

Print the length of the longest palindromic substring.

### Sample Input 1

```text
babad
```

### Sample Output 1

```text
3
```

### Sample Input 2

```text
cbbd
```

### Sample Output 2

```text
2
```

### Sample Input 3

```text
abcd
```

### Sample Output 3

```text
1
```
