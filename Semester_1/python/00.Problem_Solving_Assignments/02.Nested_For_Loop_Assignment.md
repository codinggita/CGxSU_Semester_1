# Nested For Loops – Basic Python Problems

## Instructions

* Solve all problems using **nested `for` loops**.
* Do not use `while` loops.
* Read the hint only when needed.
* Focus on understanding how the **outer loop controls rows** and the **inner loop controls items inside each row**.

---

# Quick Revision

Remember:

```text
Outer loop → Rows
Inner loop → Items inside each row
```

For example:

```text
Row 1 → inner loop runs
Row 2 → inner loop runs
Row 3 → inner loop runs
```

The **inner loop completes all its work** before the outer loop moves to the next iteration.
