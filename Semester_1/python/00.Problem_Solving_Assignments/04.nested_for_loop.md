# Python Nested `for` Loops — Practice Problems

## Scope

Students are expected to know:

- Variables
- Data types and type casting
- Numbers and arithmetic operators
- Assignment operators
- Comparison operators
- ASCII
- Boolean and logical expressions
- Strings
- `split()`
- Input and output
- Output formatting
- Conditional statements
- Nested conditions
- `match-case`
- Conditional expressions
- Single `for` loops

The main focus here is **Nested `for` Loops**.

## How to Use This Worksheet

- Questions gradually increase in difficulty.
- Do not jump directly to the final levels.
- For every question, first decide what the **outer loop** represents and what the **inner loop** represents.
- The test case shows the expected shape/result of the output. For pattern questions, spacing and line structure matter.
- Do not use functions unless a question explicitly asks for them.
- Avoid shortcuts such as `set()`, `Counter`, NumPy, `count()`, `max()`, `min()`, or `sorted()` where the question forbids them.

# Final Tracing Rule

Always trace nested loops like this:

```text
Outer loop starts
    ↓
Normal statements before inner loop execute
    ↓
Inner loop starts
    ↓
Inner loop completes ALL its iterations
    ↓
Statements after inner loop execute
    ↓
Next outer iteration starts
```

The key question is:

> **What does each loop represent, and how many times should the inner work happen for each outer value?**
