## A quick note: How to find a substring in a string

A **substring** is a sequence of characters that appears inside another string.

Example:
- Main string: `"97420"`
- Substring to find: `"420"`
- Result: The substring is present.

Python has the `in` operator:

```python
text = "97420"

if "420" in text:
    print("Caught")
else:
    print("Escaped")
```

You can also search manually with a loop. If the main string has length `n` and the substring has length `m`, compare each possible group of `m` characters:

```python
text = "97420"
target = "420"
found = False

for i in range(len(text) - len(target) + 1):
    if text[i:i + len(target)] == target:
        found = True
        break

if found:
    print("Caught")
else:
    print("Escaped")
```

The slice `text[i:i + len(target)]` takes a piece of the main string. The loop checks every possible starting position.

```

```

## Q3. Check whether both halves are palindromes

### Description

You are given a string `str` and its length `N`. The value of `N` is always even.

Divide the string into two equal halves:

- The first half contains characters from index `0` to `N // 2 - 1`.
- The second half contains characters from index `N // 2` to `N - 1`.

Check whether **both halves are palindromes**.

A palindrome is a string that reads the same from left to right and right to left.

Print `yes` if both halves are palindromes. Otherwise, print `no`.

### Input

- The first line contains an even integer `N`.
- The second line contains the string `str`.

### Constraints

- `N` is always even.
- The string contains only lowercase English letters.
- The length of the string is `N`.

### Output

Print `yes` or `no`.

### Sample Input 1

```text
6
ababcb
```

### Sample Output 1

```text
yes
```

### Explanation

The first half is `aba`, and the second half is `bcb`. Both are palindromes.

### Sample Input 2

```text
4
abdc
```

### Sample Output 2

```text
no
```

### Sample Input 3

```text
6
ababba
```

### Sample Output 3

```text
no
```

### Explanation

The first half, `aba`, is a palindrome. The second half, `bba`, is not. Therefore, the answer is `no`.
