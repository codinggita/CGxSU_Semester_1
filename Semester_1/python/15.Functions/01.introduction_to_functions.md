# 1. What Is a Function?

A **function** is a named block of code that performs a particular task.

Instead of writing the same instructions again and again, we can put those instructions inside a function and call that function whenever we need the task performed.

Example:

```python
def greet():
    print("Hello, students!")
```

Here, `greet` is the function's name. The code inside the function prints a greeting.

**Important:** Defining a function does not run its body. The body runs when we call the function.

```python
def greet():
    print("Hello, students!")

greet()
```

Output:

```text
Hello, students!
```

# 2. Why Do We Need Functions?

Imagine a program must print the same welcome message for three different students.

## Without a function

```python
print("Welcome to Python!")
print("Let's learn programming.")

print("Welcome to Python!")
print("Let's learn programming.")

print("Welcome to Python!")
print("Let's learn programming.")
```

The same instructions appear three times.

Problems with this approach:

- **Repetition:** The same code is written again and again.
- **Maintenance:** If the message changes, every copy must be updated.
- **Readability:** The program becomes longer and harder to scan.
- **Mistakes:** One copy may be updated while another is forgotten.

## With a function

```python
def show_welcome():
    print("Welcome to Python!")
    print("Let's learn programming.")

show_welcome()
show_welcome()
show_welcome()
```

Output:

```text
Welcome to Python!
Let's learn programming.
Welcome to Python!
Let's learn programming.
Welcome to Python!
Let's learn programming.
```

Now the instructions are written once and reused by calling the function.

## Key idea

**Write the instructions once. Call them whenever needed.**

A function does not automatically make every program shorter or better. It helps when a task needs a clear name, needs to be reused, or is easier to understand as a separate step.

# 3. Code Reuse

**Code reuse** means using the same code in more than one place instead of duplicating it.

Example:

```python
def print_line():
    print("--------------------")

print("Student Report")
print_line()
print("Name: Asha")
print_line()
print("Marks: 85")
print_line()
```

Output:

```text
Student Report
--------------------
Name: Asha
--------------------
Marks: 85
--------------------
```

The separator is defined once. Each call runs the same instructions.

## What happens if the separator changes?

We only change the function body:

```python
def print_line():
    print("====================")
```

Every later call uses the updated separator.

### Remember

- Defining the function creates the reusable block.
- Calling the function runs that block.
- A function call can appear more than once in a program.

# 4. Code Organization

Functions help split a large program into smaller tasks with clear names.

Imagine a simple student report:

```python
def print_heading():
    print("STUDENT REPORT")
    print("----------------")

def print_student_details():
    print("Name: Asha")
    print("Roll number: 12")

def print_result():
    print("Marks: 85")
    print("Result: Pass")

print_heading()
print_student_details()
print_result()
```

Each function handles one task:

- `print_heading()` prints the report heading.
- `print_student_details()` prints student information.
- `print_result()` prints the result.

The main part of the program shows the order of the tasks.

This is easier to understand than putting every instruction into one large block.

## Think in tasks

When reading a problem, ask:

1. What separate tasks must the program perform?
2. Can each task have a clear name?
3. Would putting a task in a function make the program easier to read or reuse?

Do not create a separate function for every single line without a reason. Functions should represent useful tasks.

# 5. Readability

**Readability** means how easily a person can understand code.

Compare these two examples.

## Example A: Instructions without meaningful names

```python
print("Asha")
print(85)
print("Pass")
```

This code prints three values, but the purpose of each value is not obvious.

## Example B: Meaningful function names


The names help readers understand what each part does.

For a program this small, three functions may be unnecessary. The example shows how names can describe tasks; in real code, create functions when they improve organization or reuse.

# 6. Defining a Function

In Python, define a function using the `def` keyword.

## Syntax

```python
def function_name():
    # Function body
    statement
```

Parts of the definition:

```python
def greet():
    print("Hello!")
```

- `def` — tells Python that a function is being defined.
- `greet` — the function name.
- `()` — holds parameters when needed. This lesson uses empty parentheses.
- `:` — starts the function body.
- Indented statements — the function body.

## Example: Define a function

```python
def say_hello():
    print("Hello!")
```

This defines the function. It does not print anything yet because the function has not been called.

## Example: Define and call

```python
def say_hello():
    print("Hello!")

say_hello()
```

Output:

```text
Hello!
```

# 7. The Function Body and Indentation

The **function body** is the indented block of statements belonging to the function.

```python
def display_message():
    print("First line")
    print("Second line")

print("Outside the function")
```

The two indented `print()` statements belong to `display_message`. The final statement is outside the function.

Because the function is not called, the output is:

```text
Outside the function
```

Now call the function:

```python
def display_message():
    print("First line")
    print("Second line")

display_message()
print("Outside the function")
```

Output:

```text
First line
Second line
Outside the function
```

## Common indentation mistake

Incorrect:

```python
def greet():
print("Hello!")
```

Python raises an `IndentationError` because the body is not indented.

Correct:

```python
def greet():
    print("Hello!")
```

Use consistent indentation. Four spaces is the standard convention.

## Which statements belong to the function?

```python
def example():
    print("A")
    print("B")

print("C")
```

Only `"A"` and `"B"` belong to the function. `"C"` is outside it.

# 8. Calling a Function (Invocation)

**Calling** or **invoking** a function means asking Python to execute its body.

Example:

```python
def clap():
    print("Clap!")

clap()
```

The line `clap()` is the function call.

## A function can be called multiple times

```python
def clap():
    print("Clap!")

clap()
clap()
clap()
```

Output:

```text
Clap!
Clap!
Clap!
```

Every call executes the body once.

## Defining is not calling

Study this code:

```python
def announce():
    print("Class begins")

print("Before")
```

Output:

```text
Before
```

The function is defined, but never called.

Now add a call:

```python
def announce():
    print("Class begins")

print("Before")
announce()
print("After")
```

Output:

```text
Before
Class begins
After
```

## Function names are case-sensitive

```python
def greet():
    print("Hello")

greet()  # Correct
Greet()  # NameError: different name
```

Python treats `greet` and `Greet` as different names.

## A call must use parentheses

```python
def greet():
    print("Hello")

greet
```

The last line refers to the function object; it does not call the function. To execute the body, write:

```python
greet()
```

# 9. Function Naming Rules and Good Practices

Function names should clearly describe the task.

## Basic naming rules

- A name may contain letters, digits, and underscores.
- A name cannot start with a digit.
- A name cannot contain spaces.
- A Python keyword, such as `if`, cannot be used as a function name.
- Names are case-sensitive.

Examples:

| Name | Valid? | Reason |
|---|---|---|
| `greet` | Yes | Clear and valid |
| `print_result` | Yes | Uses an underscore |
| `calculate_total2` | Yes | Digits may appear after the first character |
| `2calculate` | No | Starts with a digit |
| `print result` | No | Contains a space |
| `class` | No | `class` is a Python keyword |
| `PrintResult` | Yes, but not preferred | Valid name, but not the usual Python style |

## Use `snake_case`

Python convention recommends lowercase words separated by underscores.

Good names:

```python
def calculate_total():
    pass

def display_student_result():
    pass

def check_even_number():
    pass
```

Less readable names:

```python
def ct():
    pass

def DisplayStudentResult():
    pass

def checkevennumber():
    pass
```

These examples use `pass` as a placeholder for an empty body. The keyword will be studied separately.

## Choose names based on purpose

| Unclear name | Better name |
|---|---|
| `f()` | `print_receipt()` |
| `do_it()` | `display_menu()` |
| `x()` | `check_even_number()` |
| `thing()` | `show_student_details()` |

A good function name usually starts with a verb because it describes an action.

# 10. Understanding Execution Order

Python executes statements from top to bottom. A function body runs when the function is called.

```python
def first():
    print("First function")

def second():
    print("Second function")

print("Start")
second()
first()
print("End")
```

Output:

```text
Start
Second function
First function
End
```

Python does not automatically call functions in the order they were defined. The calls determine when they run.

## Example: Calling one function twice

```python
def show_star():
    print("*")

print("A")
show_star()
print("B")
show_star()
```

Output:

```text
A
*
B
*
```

# 11. Common Mistakes

### Mistake 1: Forgetting to call the function

```python
def greet():
    print("Hello")
```

No output appears because the function is not called.

### Mistake 2: Calling before the definition has executed

```python
greet()

def greet():
    print("Hello")
```

In a normal top-to-bottom script, this raises `NameError` because Python reaches the call before executing the definition.

Correct:

```python
def greet():
    print("Hello")

greet()
```

### Mistake 3: Wrong capitalization

```python
def show_result():
    print("Pass")

Show_Result()
```

The call uses a different name and raises `NameError`.

### Mistake 4: Missing parentheses

```python
def greet():
    print("Hello")

greet
```

This does not execute the function body.

### Mistake 5: Incorrect indentation

```python
def greet():
    print("Hello")
    print("Welcome")

    print("This is also inside the function")

print("This is outside the function")
```

Indentation determines which statements belong to the function.

### Mistake 6: Expecting a definition to print output

```python
def show_number():
    print(10)

print("Done")
```

Output:

```text
Done
```

The function body does not run until `show_number()` is called.
