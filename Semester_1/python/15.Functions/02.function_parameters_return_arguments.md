# Python Functions: Parameters, Arguments, Return Values, and Argument Types

## Learning Objectives

By the end of this lesson, students should be able to:

- Explain the difference between parameters and arguments.
- Define functions with multiple parameters.
- Pass positional arguments correctly.
- Return one or more values from a function.
- Store and use returned values.
- Define and use default arguments.
- Pass keyword arguments.
- Combine positional and keyword arguments correctly.
- Identify common mistakes and predict program output.

# 1. Parameters and Arguments

## 1.1 What Is a Parameter?

A **parameter** is a variable written inside the parentheses of a function definition. It receives a value when the function is called.

```python
def greet(name):
    print("Hello", name)
```

Here, `name` is a parameter.

## 1.2 What Is an Argument?

An **argument** is the actual value or expression passed to a function when calling it.

```python
def greet(name):
    print("Hello", name)

greet("Saurabh")
```

- `name` is the **parameter**.
- `"Saurabh"` is the **argument**.
- `greet("Saurabh")` is the function call.

Output:

```text
Hello Saurabh
```

### Remember the difference

| Term | Where it appears | Example |
|---|---|---|
| Parameter | Function definition | `def greet(name):` |
| Argument | Function call | `greet("Saurabh")` |

A simple way to remember it:

- **Parameter**: the variable that receives a value.
- **Argument**: the value supplied to the function.

## 1.3 How Values Reach Parameters

```python
def show_number(number):
    print(number)

show_number(25)
show_number(100)
```

Output:

```text
25
100
```

Each call supplies an argument. The parameter `number` receives the argument for that call.

## 1.4 Multiple Parameters

A function can have more than one parameter. Separate parameters with commas.

```python
def add(a, b):
    print(a + b)

add(10, 20)
```

Output:

```text
30
```

Here, `a` receives `10`, and `b` receives `20`.

A function with three parameters:

```python
def introduce(name, age, city):
    print("Name:", name)
    print("Age:", age)
    print("City:", city)

introduce("Asha", 21, "Pune")
```

Output:

```text
Name: Asha
Age: 21
City: Pune
```

The number and arrangement of arguments must match the parameters when using positional arguments.

## 1.5 Positional Arguments

A **positional argument** is assigned to a parameter based on its position in the function call.

```python
def subtract(a, b):
    print(a - b)

subtract(10, 3)
```

Output:

```text
7
```

Mapping:

- First argument `10` → first parameter `a`
- Second argument `3` → second parameter `b`

Changing the order can change the result:

```python
subtract(3, 10)
```

Output:

```text
-7
```

This happens because `a` receives `3` and `b` receives `10`.

### Common mistake: wrong number of arguments

```python
def add(a, b):
    print(a + b)

# add(5)       # TypeError: b is missing
# add(5, 10, 15)  # TypeError: too many positional arguments
```

These calls do not match the function definition.

# 2. Return Values

## 2.1 What Does `return` Do?

The `return` statement sends a value from a function back to the code that called it. It also ends that function call immediately.

```python
def add(a, b):
    return a + b

result = add(10, 20)
print(result)
```

Output:

```text
30
```

Step by step:

1. `add(10, 20)` calls the function.
2. `a` receives `10`; `b` receives `20`.
3. `a + b` evaluates to `30`.
4. `return` sends `30` back to the caller.
5. The returned value is assigned to `result`.
6. `print(result)` displays `30`.

## 2.2 `print()` Is Not the Same as `return`

`print()` displays information on the screen. `return` gives a value back to the caller so it can be stored, reused, or passed elsewhere.

### Using `print()`

```python
def add(a, b):
    print(a + b)

answer = add(2, 3)
print("Answer:", answer)
```

Output:

```text
5
Answer: None
```

Why? The function displays `5`, but it does not return a value. In Python, a function that finishes without a `return` value returns `None`.

### Using `return`

```python
def add(a, b):
    return a + b

answer = add(2, 3)
print("Answer:", answer)
```

Output:

```text
Answer: 5
```

The returned value can be used later.

## 2.3 `return` Ends the Function

Any statement after an executed `return` in the same function call is not reached.

```python
def check():
    print("Before return")
    return 10
    print("After return")

value = check()
print(value)
```

Output:

```text
Before return
10
```

`print("After return")` does not run.

## 2.4 Returning Values

A function can return the result of an expression, a variable, or a value directly.

```python
def square(number):
    result = number * number
    return result

print(square(5))
```

Output:

```text
25
```

Returning a variable:

```python
def get_message():
    message = "Welcome to Python"
    return message

text = get_message()
print(text)
```

Output:

```text
Welcome to Python
```

## 2.5 Using Returned Values

A returned value can be:

- Stored in a variable.
- Used in an expression.
- Passed as an argument to another function.
- Used in a condition.

### Store the result

```python
def multiply(a, b):
    return a * b

product = multiply(4, 5)
print(product)
```

Output:

```text
20
```

### Use the result in an expression

```python
def square(number):
    return number * number

print(square(3) + square(4))
```

Output:

```text
25
```

### Use the result in a condition

```python
def is_even(number):
    return number % 2 == 0

if is_even(8):
    print("Even")
else:
    print("Odd")
```

Output:

```text
Even
```

### Pass a returned value into another function

```python
def double(number):
    return number * 2

def add_five(number):
    return number + 5

result = add_five(double(10))
print(result)
```

Output:

```text
25
```

`double(10)` returns `20`, then `add_five(20)` returns `25`.

## 2.6 Returning Multiple Values

Python allows a function to return multiple values separated by commas.

```python
def calculate(a, b):
    total = a + b
    difference = a - b
    return total, difference

answer = calculate(10, 4)
print(answer)
```

Output:

```text
(14, 6)
```

Python packs the returned values into a tuple. So `answer` is the tuple `(14, 6)`.

### Unpack the returned values

```python
def calculate(a, b):
    return a + b, a - b

total, difference = calculate(10, 4)

print("Total:", total)
print("Difference:", difference)
```

Output:

```text
Total: 14
Difference: 6
```

The number of variables on the left should match the number of returned items when unpacking directly.

### Returning two values does not mean two separate `return` statements

```python
def get_details():
    return "Asha", 21
```

This returns one tuple containing two items.

### Common mistake: returning values on separate lines

```python
def calculate(a, b):
    return a + b
    return a - b
```

Only the first `return` executes. The second one is unreachable. To return both values, write:

```python
def calculate(a, b):
    return a + b, a - b
```

# 3. Default and Keyword Arguments

## 3.1 Default Arguments

A **default argument** is a parameter value provided in the function definition. Python uses it when the caller does not supply an argument for that parameter.

```python
def greet(name="Guest"):
    print("Hello", name)

greet()
greet("Asha")
```

Output:

```text
Hello Guest
Hello Asha
```

- `name="Guest"` defines the default value.
- `greet()` uses the default value.
- `greet("Asha")` supplies an argument, so `"Asha"` is used instead.

### Multiple default parameters

```python
def introduce(name, city="Pune"):
    print(name, "is from", city)

introduce("Asha")
introduce("Rahul", "Mumbai")
```

Output:

```text
Asha is from Pune
Rahul is from Mumbai
```

### Important rule: required parameters before default parameters

Correct:

```python
def introduce(name, city="Pune"):
    print(name, city)
```

Incorrect:

```python
# This causes a SyntaxError:
# def introduce(city="Pune", name):
#     print(name, city)
```

A parameter without a default value cannot follow a parameter with a default value in the same ordinary parameter list.

### Changing a default value for one call

```python
def power(number, exponent=2):
    return number ** exponent

print(power(5))
print(power(5, 3))
```

Output:

```text
25
125
```

When `exponent` is omitted, it defaults to `2`. Supplying `3` overrides the default for that call.

## 3.2 Keyword Arguments

A **keyword argument** supplies a value by naming the parameter.

```python
def introduce(name, age):
    print(name, age)

introduce(name="Asha", age=21)
```

Output:

```text
Asha 21
```

The argument names make the call easier to understand.

### Keyword arguments can be supplied in a different order

```python
def introduce(name, age, city):
    print(name, age, city)

introduce(city="Pune", age=21, name="Asha")
```

Output:

```text
Asha 21 Pune
```

Because each value is matched by parameter name, the order of keyword arguments does not matter.

### Keyword argument names must match parameter names

```python
def greet(name):
    print("Hello", name)

greet(name="Asha")  # Correct
```

Using a name that is not a parameter, such as `greet(username="Asha")`, raises a `TypeError`.

## 3.3 Combining Positional and Keyword Arguments

You can combine positional and keyword arguments in the same call. **Positional arguments must come before keyword arguments.**

Correct:

```python
def describe(name, age, city):
    print(name, age, city)

describe("Asha", age=21, city="Pune")
```

Output:

```text
Asha 21 Pune
```

Here:

- `"Asha"` is assigned positionally to `name`.
- `age=21` assigns `21` to `age`.
- `city="Pune"` assigns `"Pune"` to `city`.

Incorrect:

```python
# This causes a SyntaxError:
# describe(name="Asha", 21, city="Pune")
```

A positional argument cannot follow a keyword argument in a function call.

### Do not provide the same parameter twice

Incorrect:

```python
# This causes a TypeError:
# describe("Asha", name="Rahul", city="Pune")
```

The first positional argument already assigns `"Asha"` to `name`. The keyword argument `name="Rahul"` tries to assign `name` again.

### Combining positional arguments with default values

```python
def order(item, quantity=1, price=100):
    print(item, quantity, price)

order("Notebook")
order("Notebook", 3)
order("Notebook", price=50)
order("Notebook", 3, 50)
```

Output:

```text
Notebook 1 100
Notebook 3 100
Notebook 1 50
Notebook 3 50
```

This example shows how defaults are used when values are omitted and how keyword arguments can target a specific parameter.

# 4. Common Mistakes and Edge Cases

## Mistake 1: Confusing a parameter with an argument

```python
def greet(name):  # name is a parameter
    print(name)

greet("Asha")     # "Asha" is an argument
```

## Mistake 2: Expecting `print()` to return a value

```python
def get_number():
    print(10)

result = get_number()
print(result)
```

Output:

```text
10
None
```

Use `return 10` if the caller needs to receive the value.

## Mistake 3: Forgetting that `return` ends the function

```python
def example():
    return 5
    print("Hello")  # Never reached
```

## Mistake 4: Supplying too few or too many arguments

```python
def add(a, b):
    return a + b

# add(5)          # TypeError: missing required argument
# add(5, 2, 1)    # TypeError: too many positional arguments
```

## Mistake 5: Putting positional arguments after keyword arguments

```python
# Incorrect:
# greet(name="Asha", "Pune")
```

## Mistake 6: A default parameter does not make every parameter optional

```python
def greet(name, message="Hello"):
    print(message, name)

greet("Asha")  # Valid
# greet()      # TypeError: name is required
```

## Edge case: a function returns `None`

A function returns `None` if it reaches the end without executing a `return` statement with a value, or if it executes `return` by itself.

```python
def stop():
    return

print(stop())
```

Output:

```text
None
```

## Edge case: returning multiple values

```python
def one_value():
    return 10

def two_values():
    return 10, 20

print(one_value())   # 10
print(two_values())  # (10, 20)
```

The second function returns a tuple.

# 8. Lesson Summary

- A **parameter** is a variable in a function definition.
- An **argument** is a value passed when calling a function.
- **Multiple parameters** let a function receive multiple values.
- **Positional arguments** are matched by order.
- `return` sends a value back to the caller and ends the current function call.
- A function without an explicit returned value produces `None`.
- A function can return multiple values; Python packs them into a tuple.
- **Default arguments** are used when the caller omits those arguments.
- **Keyword arguments** match values to parameters by name.
- In a function call, positional arguments must appear before keyword arguments.
- A parameter with a default value must come after required parameters in a normal function definition.
