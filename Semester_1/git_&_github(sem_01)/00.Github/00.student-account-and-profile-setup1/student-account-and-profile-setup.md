# Student Account & Software Setup Guide

This repository contains the setup guide for all students joining the program.

## 📌 Objective

Every student must complete the following account setup and software installation process before starting the program.

These accounts and tools will be used throughout the program for:
- Coding
- Assignments
- Projects
- Professional development

---

# Step 1: Create Your Official Gmail Account

Create a new Gmail account using the following format:

```
firstname.lastname.cg@gmail.com
```

### Examples

- rahul.sharma.cg@gmail.com
- priya.patel.cg@gmail.com
- arjun.mehta.cg@gmail.com

### Guidelines

- Use your real first and last name.
- Avoid unnecessary numbers or special characters.
- Use this email for all CodingGita-related accounts.
- Keep your password secure.
- Enable Two-Factor Authentication (2FA).

---

# Step 2: Create Your LeetCode Account

**Website:** https://leetcode.com

Register using your new Gmail account.

After creating your account:

- Verify your email address.
- Complete your profile.
- Upload a professional profile photograph where your face is clearly visible.

---

# Step 3: Create Your GitHub Account

**Website:** https://github.com

Register using the same new Gmail account.

After creating your account:

- Choose a professional username.
- Verify your email address.
- Enable Two-Factor Authentication (recommended).
- Complete your profile.
- Upload the same professional profile photograph.

---

# Step 4: Create Your LinkedIn Profile

**Website:** https://www.linkedin.com

Create your LinkedIn profile using the same new Gmail account.

After creating your profile:

- Upload a professional profile photograph where your face is clearly visible.
- Add your basic educational information.
- Write a short professional headline.
- Complete the essential profile details.

Your LinkedIn profile will be used throughout the program for:

- Networking
- Internships
- Placement opportunities

---

# Step 5: Create Your Sololearn Account

**Website:** https://www.sololearn.com

Register using your new Gmail account.

After creating your account:

- Verify your email address.
- Complete your profile.
- Upload the same professional profile photograph.

---

# Software Installation

## 1. Install Figma Desktop

**Download:** https://www.figma.com/downloads/

- Install the desktop application.
- Sign in using your new Gmail account.

---

## 2. Install Visual Studio Code (VS Code)

**Download:** https://code.visualstudio.com

- Download the latest stable version.
- Install Visual Studio Code.

---

## 3. Install Git

**Download:** https://git-scm.com/downloads

- Download Git for your operating system.
- Install Git.
- Git will be used throughout the program for version control and project collaboration.

---

# Professional Profile Photo Guidelines

Use the **same professional photograph** across all platforms.

Your profile photo should:

- Clearly show your face.
- Have good lighting.
- Be recent.
- Have a clean and professional appearance.
- Avoid sunglasses, heavy filters, group photos, or distracting backgrounds.
