# Assignment – Objects as Reference Types in JavaScript

---

### Section 1: Primitive Types vs Reference Types

1. Create a number variable and assign it to a second variable. Change the value of the second variable and print both. Write one sentence explaining why the first variable did not change.

2. Take a string variable, assign it to another variable, then completely replace the value of the second variable with a different string. Print both variables and state whether they still share the same value or not.

3. Create a boolean variable set to `true`. Assign it to a second variable and then set the second variable to `false`. Print both variables and explain in one line what this tells you about how primitive values are stored.

4. Write a short program that shows a primitive value being copied and then modified independently. After the code, write two lines describing the difference between storing a value and storing a reference.

---

### Section 2: Objects Are Stored by Reference

1. Create an object that stores a student’s name and age. Assign the object to a second variable. Print both variables. Then write one sentence explaining what each variable actually holds in memory.

2. Create an object with three properties. Assign it to two more variables so that three variables point to the same object. Change one property using the third variable and print the object using the first variable. Explain why the change is visible.

3. Draw (or clearly describe in text) the memory situation after this code runs:  
```javascript
var student = { name: "Vikram", age: 19 };
var temp = student;
```  
Show what lives in the variable and what lives in the actual memory location.

4. Create an object and three different variables that all refer to it. Change different properties through different variables and print the final state of the object from any one of the variables.

---

### Section 3: Copying Objects Does NOT Create a New Object

1. Create an object with name and marks. Assign it to a second variable using `=`. Change the marks through the second variable and print both objects. Write one clear sentence stating whether a new object was created or not.

2. Write code that starts with one object and creates a second variable by simple assignment. Modify a property through the new variable. Then answer: How many objects exist in memory after the assignment?

3. Create two variables that point to the same object through assignment. Re-assign a completely new object to the second variable. Print both variables and explain what happened to the original object.

4. Write a short comparison: show the result of assigning a number versus assigning an object. After both cases, state in one line what the assignment operator actually copies in each case.

---

### Section 4: Changes Through Any Reference Affect the Same Object

1. Create an object and two references to it. Change the name property through the first reference and the marks property through the second reference. Print the object once and confirm both changes are present.

2. Start with this code and complete it so that both variables end up showing the updated values:  
```javascript
var s1 = { name: "Arvind", marks: 78 };
var s2 = s1;
```  
Then change two different properties using the two different variables and print the final object.

3. Create three variables that all refer to the same student object. Update the name using the first variable, the course using the second variable, and the marks using the third variable. Print the object from any variable to show the combined result.

4. Create an object, make a second reference, and then change a property through the second reference. Immediately after that, re-assign a brand new object to the second reference. Print both variables and explain which changes affected the original object.

### Section 5: Real Life Example (CodingGita)

1. Create a student profile object with name, course, and marks. Create a second variable that holds a reference to the same profile (as if it is used for display). Update the marks through the display variable and print both the original profile and the display variable.

2. Simulate a CodingGita system where the same student profile is accessed from two places. Change the course name from one place and the marks from the other place. Print the final profile to show that both places see the latest data.

3. Create a profile object. Make two additional references to it. Change the name through the first reference and the marks through the second reference. Print the original profile and confirm both updates are visible.

4. Write a short scenario: a student’s marks are updated from a “result display” screen that holds only a reference to the main profile. Show with code that the main profile also reflects the new marks, and explain why this happens in one sentence.

### Section 6: Arrays Behave the Same Way

1. Create an array of three numbers. Assign it to a second variable. Add a new number using the second variable and print both arrays. Write one sentence stating what this proves about arrays.

2. Create an array and a second reference to it. Change the value at index 0 through the second reference. Print the original array and explain why the change appears there.

3. Start with an array. Create a second variable by assignment. Use `push` on one variable and `pop` on the other. Print the final array from both variables and state how many arrays actually exist in memory.

4. Create two variables that point to the same array. Modify the array using both variables in different ways (index change and adding an element). Print the array once at the end and confirm all changes are present.

---

### Section 7: How to Truly Copy an Object

1. Create a student object with name and marks. Manually create a second independent object by copying each property one by one. Change the marks in the second object and print both objects to prove they are separate.

2. Write code that creates an object and then builds a true independent copy without using the assignment operator. After creating the copy, change two properties in the copy and show that the original object stays the same.

3. Create an object. First make a reference copy using `=` and show that changing it affects the original. Then create a manual independent copy of the same original object and show that changing the manual copy leaves the original untouched.

4. Write a small function that receives an object and returns a new object with the same property values (manual copy). Call the function, change a property in the returned object, and prove the original object was not modified.

### Section 9: Common Mistakes

1. Write code that makes the common mistake of assuming `var a = b` creates a new independent object. Then correct the same code by creating a true independent copy and show the difference in behavior.

2. Create an array and assign it to a second variable. Modify the array through the second variable (this is the common mistake). Then create a correct independent copy of the original array by manually pushing each element into a new array and prove the two arrays are now separate.

3. Create two different objects that happen to have the same property values. Compare them using `===` and print the result. Explain in one sentence why the comparison returns `false`.

4. Write a function that receives an object and changes one of its properties. Call the function with a student object and then print the original object outside the function. Explain why the original object shows the change even though it was not returned from the function.
