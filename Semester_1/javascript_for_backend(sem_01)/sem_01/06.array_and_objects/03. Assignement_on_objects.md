# Assignment – Objects in JavaScript
---
### Section 1: What Is an Object?
1. Create an object named `book` with three properties: `title`, `author`, and `pages`.
2. Create an object that stores a string, a number, and a boolean value.
3. Create an object named `person` that contains a string, a number, a boolean, an array, and a nested object.
4. Create an object that includes all six types of values: string, number, boolean, array, nested object, and a method.
5. Write an object named `student` that has a method returning a greeting message using the student’s name.

---

### Section 2: Why Do We Need Objects?
1. Convert these three variables into one object: `name = "Rahul"`, `age = 20`, `city = "Delhi"`.
2. Create one object to store details of a product (name, price, and availability).
3. Explain in one or two lines why using an object is better than using many separate variables.
4. Create objects for a student and a book. Show how related data is grouped together.
5. Given five separate variables about a car, convert them into a single well-structured object.

---

### Section 3: Creating Objects
1. Create a student object using object literal syntax.
2. Create an empty object using `new Object()` and add three properties to it.
3. Create a constructor function named `Car` that accepts `brand` and `model`, then create two car objects using it.
4. Create the same employee data once using object literal and once using a constructor function.
5. Create three student objects using a constructor function and store them in an array.

---

### Section 4: Accessing Object Properties
1. Access and print the `name` and `age` of a student object using dot notation.
2. Access a property that has a space in its key using bracket notation.
3. Store a property name in a variable and access its value using that variable.
4. Create an object with five properties and print all values using both dot and bracket notation.
5. Write code that correctly accesses a property when the key is stored in a variable (show both correct and incorrect ways).

---

### Section 5: Adding New Properties
1. Create an object with two properties and then add a third property to it.
2. Add a property whose key contains a space to an existing object.
3. Start with an empty object and add four properties one by one.
4. Create a student object and add both a normal property and a property with a space in the key.
5. Add multiple properties to an object using both dot notation and bracket notation in the same program.

---

### Section 6: Updating Property Values
1. Update the `age` of a student object and print the object.
2. Update one property using dot notation and another using bracket notation.
3. Create an object, print it, update two properties, and print it again to show the changes.
4. Change the value of a property that was originally a number into a string and observe the result.
5. Write a small program that updates properties of an object based on user-defined new values.

---

### Section 7: Deleting Properties
1. Delete one property from a student object and print the object.
2. Try deleting a property that does not exist and observe the result.
3. Create an object with four properties, delete two of them, and print the final object.
4. Write code that deletes a property only if it exists in the object.
5. Create an object, delete a property, and then try to access the deleted property. Explain what happens.

---

### Section 8: Objects Can Store Anything
1. Create an object that contains an array as one of its properties.
2. Create an object that contains another object inside it.
3. Create a product object that has an array of colors and a nested manufacturer object.
4. Add a method to an object that returns information using other properties of the same object.
5. Create one object that contains a string, number, array, nested object, and a method. Call the method and print selected values.

### Section 9: Methods & the `this` Keyword
1. Create an object with a method that prints a simple message.
2. Create an object with a method that uses `this` to access the object’s name.
3. Create a student object with a method `getDetails` that returns name and marks using `this`.
4. Write a method that checks whether a student has passed (marks >= 40) using `this`.
5. Create an object with two methods: one returns the full name and the other checks adult status using `this`.

### Section 10: Looping Through an Object
1. Use a `for...in` loop to print all keys of an object.
2. Use a `for...in` loop to print all values of an object.
3. Write a `for...in` loop that prints both key and value in the format `key: value`.
4. Count the total number of properties in an object using a `for...in` loop.
5. Write a loop that prints only those properties whose values are numbers.

### Section 11: Nested Objects

### Section 12: Array of Objects

### Section 13: Objects vs Arrays

### Section 15: Complete Example
