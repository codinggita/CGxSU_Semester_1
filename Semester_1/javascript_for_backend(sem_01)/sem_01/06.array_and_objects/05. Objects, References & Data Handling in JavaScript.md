# Objects, References & Data Handling in JavaScript

---

### 1. Reference Datatype & Value Datatype (Revision)

In JavaScript, data is stored in two different ways.  
**Value datatypes** (primitives) store the actual value directly.  
**Reference datatypes** (non-primitives) store a reference (memory address) that points to the actual data.

| Point                  | Value Datatype (Primitive)          | Reference Datatype (Non-Primitive)      |
|------------------------|-------------------------------------|-----------------------------------------|
| Also Called            | Primitive Type                      | Non-Primitive / Reference Type          |
| Examples               | number, string, boolean, null, undefined | object, array, function              |
| Stored As              | Actual value                        | Reference (memory address)              |
| Copy Behavior          | Creates an independent copy         | Copies only the reference               |
| Change Effect          | Changing one does not affect other  | Changing one affects all references     |

**Simple Example**

```javascript
// Value Datatype
var a = 25;
var b = a;
b = 50;
console.log(a);   // 25

// Reference Datatype
var obj1 = { name: "Chetan" };
var obj2 = obj1;
obj2.name = "Rohan";
console.log(obj1.name);   // Rohan
```

### 2. Call by Value & Call by Reference (Call by Sharing)

In JavaScript, **everything is Call by Value**.

- For primitives → the actual value is copied.
- For objects and arrays → the **value of the reference** (address) is copied. This is called **Call by Sharing** (or Call by Reference Value).

True **Call by Reference** (where you can change the original variable itself) exists in languages like **C**, but **not in JavaScript**.

| Point                  | Call by Value (Primitives)          | Call by Sharing (Objects & Arrays)      |
|------------------------|-------------------------------------|-----------------------------------------|
| Used For               | number, string, boolean             | Objects and Arrays                      |
| What is Passed         | A copy of the actual value          | A copy of the reference (address)       |
| Effect on Original     | Original remains unchanged          | Changes to the content affect original  |
| Can reassign original? | No                                  | No (only content can be changed)        |

**Simple Example**

```javascript
// Call by Value (Primitive)
function changeNumber(x) {
    x = 100;
}
var num = 40;
changeNumber(num);
console.log(num);   // 40  (original not changed)

// Call by Sharing (Object)
function changeMarks(student) {
    student.marks = 95;     // content changed
}
var s = { name: "Priya", marks: 70 };
changeMarks(s);
console.log(s.marks);   // 95  (content changed)
```

### 3. Immutability & Mutability in JavaScript

**Mutable** means data can be changed after it is created.  
**Immutable** means data cannot be changed after it is created.

By default:
- Primitives are **immutable**
- Objects and Arrays are **mutable**

However, we can make objects and arrays **immutable** using `Object.freeze()`.

| Point                  | Mutable                             | Immutable                               |
|------------------------|-------------------------------------|-----------------------------------------|
| Meaning                | Can be modified after creation      | Cannot be modified after creation       |
| Applies To             | Objects and Arrays (by default)     | Primitives + frozen objects/arrays      |
| Behavior               | Properties/elements can be changed  | Any change is ignored or creates new value |
| Example                | `obj.name = "New"` works            | `Object.freeze(obj)` prevents changes   |

**Simple Example**

```javascript
// Mutable Object
var user = { name: "Meera" };
user.name = "Sneha";
console.log(user.name);   // Sneha

// Making Object Immutable
var student = { name: "Harsh", marks: 88 };
Object.freeze(student);

student.marks = 95;       // ignored
student.city = "Pune";    // ignored
console.log(student);     // { name: "Harsh", marks: 88 }

// Immutable String (Primitive)
var str = "Hello";
str[0] = "h";
console.log(str);         // Hello
```

### 4. Useful Object Built-in Methods

#### a. Creating Methods Inside Objects
```javascript
var student = {
    name: "Harsh",
    marks: 88,
    show: function() {
        console.log(this.name + " scored " + this.marks);
    }
};
student.show();
```

#### b. Understanding `this`
`this` refers to the current object.

```javascript
var car = {
    brand: "Tata",
    model: "Nexon",
    info: function() {
        console.log(this.brand + " " + this.model);
    }
};
car.info();   // Tata Nexon
```

#### c. Checking Property Existence (`in`)
```javascript
var book = { title: "JavaScript", pages: 250 };
console.log("title" in book);    // true
console.log("author" in book);   // false
```

#### d. `Object.keys()`
Returns an array of all property names.
```javascript
var user = { name: "Ananya", age: 21 };
console.log(Object.keys(user));   // ["name", "age"]
```

#### e. `Object.values()`
Returns an array of all property values.
```javascript
console.log(Object.values(user)); // ["Ananya", 21]
```

#### f. `Object.entries()`
Returns an array of key-value pairs.
```javascript
console.log(Object.entries(user));
// [["name", "Ananya"], ["age", 21]]
```

#### g. `Object.assign()`
Copies properties from source objects into a target object.
```javascript
var target = { a: 1 };
Object.assign(target, { b: 2 }, { c: 3 });
console.log(target);   // { a: 1, b: 2, c: 3 }
```

#### h. `Object.hasOwn()` (Modern)
Checks if the property belongs directly to the object (not inherited).
```javascript
console.log(Object.hasOwn(user, "name"));     // true
console.log(Object.hasOwn(user, "toString")); // false
```

### 5. Copying Objects & Arrays

#### Copying Objects

**Using `Object.assign()`**
```javascript
var s1 = { name: "Chirag", marks: 82 };
var s2 = Object.assign({}, s1);
s2.marks = 95;
console.log(s1.marks);   // 82
```

**Using Spread Operator**
```javascript
var s3 = { ...s1 };
s3.name = "Kabir";
console.log(s1.name);    // Chirag
```

#### Copying Arrays

**Using `slice()`**
```javascript
var arr1 = [10, 20, 30];
var arr2 = arr1.slice();
arr2.push(40);
console.log(arr1);       // [10, 20, 30]
```

**Using Spread Operator**
```javascript
var arr3 = [...arr1];
arr3[0] = 99;
console.log(arr1);       // [10, 20, 30]
```

> Note: Both create **shallow copies**.

### 6. JSON (Optional but Useful)

#### a. What is JSON?
JSON stands for **JavaScript Object Notation**.  
It is a lightweight text format used to store and transfer data between applications.

**JavaScript Object Example**
```javascript
var person = {
    name: "Ravi",
    age: 23,
    city: "Jaipur"
};
```

**Equivalent JSON**
```json
{
    "name": "Ravi",
    "age": 23,
    "city": "Jaipur"
}
```

#### b. Difference between JavaScript Objects and JSON

| Point                  | JavaScript Object                   | JSON                                    |
|------------------------|-------------------------------------|-----------------------------------------|
| Functions              | Can contain functions               | Cannot contain functions                |
| Key Format             | Keys can be without quotes          | Keys must be in double quotes           |
| Usage                  | Used in actual code                 | Used for data transfer (API, files)     |
| Supported Values       | Supports undefined, functions, symbols | Only string, number, boolean, array, object, null |
| Flexibility            | More flexible                       | Strict format rules                     |
| Comments               | Allows comments                     | Does not allow comments                 |

#### c. `JSON.stringify()`
Converts a JavaScript object into a JSON string.
```javascript
var student = { name: "Sneha", marks: 91 };
var jsonStr = JSON.stringify(student);
console.log(jsonStr);   // {"name":"Sneha","marks":91}
```

#### d. `JSON.parse()`
Converts a JSON string back into a JavaScript object.
```javascript
var obj = JSON.parse(jsonStr);
console.log(obj.name);  // Sneha
```

### 7. Shallow Copy vs Deep Copy

A **shallow copy** copies only the top-level properties. Nested objects still share the same reference.  
A **deep copy** creates a completely independent copy of all levels.

| Point                  | Shallow Copy                        | Deep Copy                               |
|------------------------|-------------------------------------|-----------------------------------------|
| What is Copied         | Only the first level                | Everything (all levels)                 |
| Nested Objects         | Still shared (same reference)       | Completely independent                  |
| Changes Affect Original? | Yes (for nested data)             | No                                      |
| Common Methods         | `Object.assign()`, spread (`...`), `slice()` | `JSON.parse(JSON.stringify())`     |

**Simple Example**

```javascript
var original = {
    name: "Priya",
    address: { city: "Surat" }
};

// Shallow Copy
var shallow = Object.assign({}, original);
shallow.address.city = "Ahmedabad";
console.log(original.address.city);   // Ahmedabad

// Deep Copy
var deep = JSON.parse(JSON.stringify(original));
deep.address.city = "Rajkot";
console.log(original.address.city);   // Ahmedabad
```

### 8. Revision: Nested Objects, Arrays of Objects & Complex Structures

#### a. Nested Objects

**What is a Nested Object?**  
An object that contains another object as a property.

**Creating Nested Objects**
```javascript
var student = {
    name: "Rohan",
    address: {
        city: "Pune",
        pincode: 411001
    }
};
```

**Accessing Nested Properties**
```javascript
console.log(student.address.city);           // Pune
console.log(student["address"]["pincode"]);  // 411001
```

**Updating Nested Properties**
```javascript
student.address.city = "Mumbai";
```

**Adding & Deleting Nested Properties**
```javascript
student.address.state = "Maharashtra";   // add
delete student.address.pincode;          // delete
```

**Traversing Nested Objects**
```javascript
for (var key in student.address) {
    console.log(key + ": " + student.address[key]);
}
```

#### b. Arrays of Objects

**What is an Array of Objects?**  
An array where each element is an object.

**Creating**
```javascript
var students = [
    { name: "Meera", marks: 88 },
    { name: "Kabir", marks: 76 },
    { name: "Ananya", marks: 92 }
];
```

**Accessing**
```javascript
console.log(students[0]);         // first object
console.log(students[1].name);    // Kabir
```

**Adding New Object**
```javascript
students.push({ name: "Harsh", marks: 81 });
```

**Updating Property**
```javascript
students[0].marks = 90;
```

**Deleting Object**
```javascript
students.splice(1, 1);   // removes Kabir
```

**Traversing**
```javascript
for (var i = 0; i < students.length; i++) {
    console.log(students[i].name + " - " + students[i].marks);
}
```

**Searching**
```javascript
var found = null;
for (var i = 0; i < students.length; i++) {
    if (students[i].name === "Ananya") {
        found = students[i];
        break;
    }
}
```

**Filtering**
```javascript
var toppers = [];
for (var i = 0; i < students.length; i++) {
    if (students[i].marks >= 85) {
        toppers.push(students[i]);
    }
}
```

**Sorting**
```javascript
students.sort(function(a, b) {
    return b.marks - a.marks;
});
```

**Calculating Total & Average**
```javascript
var total = 0;
for (var i = 0; i < students.length; i++) {
    total += students[i].marks;
}
var average = total / students.length;
```

#### c. Objects Inside Objects and Arrays

**Nested Arrays inside Objects**
```javascript
var course = {
    name: "Full Stack",
    topics: ["HTML", "CSS", "JavaScript"]
};
console.log(course.topics[1]);   // CSS
```

**Arrays of Objects inside Objects**
```javascript
var batch = {
    name: "Morning Batch",
    students: [
        { name: "Ravi", city: "Delhi" },
        { name: "Sneha", city: "Jaipur" }
    ]
};
```

**Accessing Deeply Nested Data**
```javascript
console.log(batch.students[0].city);   // Delhi
```

**Traversing Complex Structures**
```javascript
for (var i = 0; i < batch.students.length; i++) {
    console.log(batch.students[i].name + " from " + batch.students[i].city);
}
```

---

**Quick Reminder**  
- Primitives → stored by value  
- Objects & Arrays → stored by reference  
- JavaScript uses Call by Sharing for objects  
- Use `Object.freeze()` to make objects/arrays immutable
