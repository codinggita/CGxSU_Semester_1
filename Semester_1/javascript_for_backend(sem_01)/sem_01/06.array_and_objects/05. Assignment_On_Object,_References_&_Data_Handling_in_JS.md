### Section 7: Shallow Copy vs Deep Copy

**Practical Questions**

1. Create an object with a nested `address` object. Make a shallow copy using `Object.assign()`. Change the city in the copy and print the original object.

2. Create the same nested object. Make a deep copy using `JSON.parse(JSON.stringify())`. Change the city in the deep copy and print the original.

3. Create an object containing an array. Make a shallow copy and push a new element into the array through the copy. Check the original.

4. Create a nested object and make both shallow and deep copies. Modify both copies and compare the effect on the original.

**Code-Based Questions**

5. Predict the output:
```javascript
var original = { name: "Priya", address: { city: "Surat" } };
var shallow = Object.assign({}, original);
shallow.address.city = "Ahmedabad";
console.log(original.address.city);
```

6. Predict the output:
```javascript
var original = { name: "Priya", address: { city: "Surat" } };
var deep = JSON.parse(JSON.stringify(original));
deep.address.city = "Rajkot";
console.log(original.address.city);
```

**Theory Question**

7. What is the difference between Shallow Copy and Deep Copy? When should we prefer a deep copy?
