# Fundamentals

## 1. Introduction

### Overview

TypeScript is a strongly typed programming language developed by Microsoft. It is a superset of JavaScript, which means valid JavaScript code is also valid TypeScript code.

TypeScript adds a static type system and other features to JavaScript. TypeScript code is compiled into JavaScript before it is executed.

### vs JavaScript

| JavaScript                               | TypeScript                                       |
| ---------------------------------------- | ------------------------------------------------ |
| Dynamically typed                        | Statically typed                                 |
| Types are checked at runtime             | Types are checked during development/compilation |
| No type annotations                      | Supports type annotations                        |
| `.js` and `.jsx`                         | `.ts` and `.tsx` files                           |
| Runs directly in JavaScript environments | Usually compiled/transformed to JavaScript       |

TypeScript does not replace JavaScript at runtime. The JavaScript output is what ultimately runs in the browser, Node.js, or another JavaScript runtime.

---

### Static Typing

Static typing means that types are known and checked before the program runs.

TypeScript can identify incompatible operations during development or compilation.

```ts
let age: number = 25;
```

Here, `age` is declared as a `number`.

---

### Dynamic Typing

Dynamic typing means that variable types are determined at runtime and can change during execution.

JavaScript is dynamically typed.

```js
let value = 10;
value = "hello";
```

The same variable can hold values of different types.

---

### Compile-Time vs Runtime

#### Compile-Time

Compile-time refers to the stage before the program runs.

TypeScript checks types during this stage.

```text
TypeScript Code
      ↓
Type Checking
      ↓
Compilation
      ↓
JavaScript
```

#### Runtime

Runtime is when the generated JavaScript is actually executed.

TypeScript types do not exist in the generated JavaScript at runtime.

```text
JavaScript
      ↓
JavaScript Runtime
      ↓
Program Execution
```

---

### Compilation

TypeScript code is transformed into JavaScript using the TypeScript compiler.

The TypeScript compiler is commonly accessed using `tsc`.

```bash
tsc
```

A TypeScript file:

```text
app.ts
```

can be compiled into JavaScript:

```text
app.js
```

TypeScript compilation can also perform type checking.

---

TypeScript can be used with different JavaScript runtimes, frameworks, and build tools.

---

### Installation

TypeScript can be installed as a project dependency.

```bash
npm install -D typescript
```

The TypeScript compiler can then be used through the project configuration or package scripts.

A global installation is also possible:

```bash
npm install -g typescript
```

# 2. Basic Types

TypeScript provides types for describing the kinds of values that variables, parameters, properties, and return values can contain.

## String

The `string` type represents textual values.

```ts
let name: string = "Satya";
```

---

## Number

The `number` type represents numeric values.

```ts
let age: number = 25;
```

TypeScript uses `number` for both integer and floating-point numbers.

---

## Boolean

The `boolean` type represents `true` or `false`.

```ts
let isActive: boolean = true;
```

---

## Null

The `null` type represents the intentional absence of a value.

```ts
let value: null = null;
```

When `strictNullChecks` is enabled, `null` is treated separately from other types.

---

## Undefined

The `undefined` type represents an undefined value.

```ts
let value: undefined = undefined;
```

---

## BigInt

The `bigint` type represents integers larger than the range safely represented by the `number` type.

```ts
let largeNumber: bigint = 9007199254740991n;
```

BigInt values use the `n` suffix.

---

## Symbol

The `symbol` type represents unique values created using `Symbol`.

```ts
let id: symbol = Symbol("id");
```

Each symbol is unique, even when created with the same description.

---

## Any

The `any` type disables most TypeScript type checking for a value.

```ts
let value: any = "hello";
```

A value of type `any` can be assigned different types without TypeScript reporting type errors.

`any` should be used carefully because it removes type safety.

---

## Unknown

The `unknown` type represents a value whose type is not known.

```ts
let value: unknown;
```

Unlike `any`, a value of type `unknown` cannot be used as a specific type until its type has been narrowed.

```ts
let value: unknown = "hello";

if (typeof value === "string") {
	value.toUpperCase();
}
```

`unknown` is safer than `any` when the type of a value is not known.

---

## Never

The `never` type represents values that never occur.

It is commonly used for:

- Functions that never return
- Operations that cannot complete normally
- Exhaustiveness checking

```ts
function fail(): never {
	throw new Error("Failed");
}
```

A function returning `never` does not successfully return a value to its caller.

---

## Void

The `void` type represents the absence of a useful return value.

It is commonly used for functions that do not return a value.

```ts
function logMessage(): void {
	console.log("Hello");
}
```

`void` and `never` are different:

- `void` means the function completes without returning a useful value.
- `never` means the function does not complete normally.

---

## Object

The `object` type represents non-primitive values.

```ts
let user: object = {
	name: "Satya",
};
```

Primitive values such as strings, numbers, and booleans are not assignable to `object`.

For structured objects, specific object types, interfaces, or type aliases are generally more useful than the broad `object` type.

---

# 3. Arrays & Tuples

## Typed Arrays

An array type specifies the type of elements that an array can contain.

### Array Type Syntax

```ts
let numbers: number[] = [1, 2, 3];
```

All elements are expected to be numbers.

Another syntax is:

```ts
let names: string[] = ["A", "B", "C"];
```

---

## Array Generic Syntax

Arrays can also be written using the generic `Array<T>` syntax.

```ts
let numbers: Array<number> = [1, 2, 3];

let names: Array<string> = ["A", "B"];
```

Both `number[]` and `Array<number>` describe arrays containing numbers.

---

## Tuples

A tuple represents an array with a fixed number of elements where each position can have a specific type.

```ts
let user: [number, string] = [1, "Satya"];
```

The first element must be a `number`, and the second must be a `string`.

Unlike a normal array, the order and types of tuple elements are defined.

---

## Rest Tuple Elements

Tuples can contain rest elements.

```ts
let values: [string, ...number[]] = ["numbers", 1, 2, 3];
```

The first element must be a string, followed by zero or more numbers.
