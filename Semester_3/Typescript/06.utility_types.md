# Utility Types

## 1. Utility Types

Utility types are built-in generic types provided by TypeScript for transforming existing types.

They allow common type transformations without manually defining a new type each time.

---

## `Partial`

`Partial<T>` makes all properties of a type optional.

```ts
interface User {
	id: number;
	name: string;
	email: string;
}

type UpdateUser = Partial<User>;
```

`UpdateUser` has the same properties as `User`, but all properties are optional.

---

## `Required`

`Required<T>` makes all properties of a type required.

```ts
interface User {
	id?: number;
	name?: string;
}

type CompleteUser = Required<User>;
```

The optional properties become required.

---

## `Readonly`

`Readonly<T>` makes all properties of a type readonly.

```ts
interface User {
	id: number;
	name: string;
}

type ReadonlyUser = Readonly<User>;
```

Properties of `ReadonlyUser` cannot be reassigned.

---

## `Pick`

`Pick<T, K>` creates a type containing only the selected properties from another type.

```ts
interface User {
	id: number;
	name: string;
	email: string;
}

type UserPreview = Pick<User, "id" | "name">;
```

The resulting type contains only `id` and `name`.

---

## `Omit`

`Omit<T, K>` creates a type by removing selected properties.

```ts
interface User {
	id: number;
	name: string;
	password: string;
}

type PublicUser = Omit<User, "password">;
```

The resulting type contains every property except `password`.

---

## `Record`

`Record<K, T>` creates an object type whose keys are `K` and whose values are `T`.

```ts
type Scores = Record<string, number>;
```

The object can have string keys with number values.

It can also be used with a specific union of keys.

```ts
type Role = "admin" | "user";

type Permissions = Record<Role, string[]>;
```

---

## `Exclude`

`Exclude<T, U>` removes from `T` all union members that are assignable to `U`.

```ts
type Status = "pending" | "success" | "error";

type ActiveStatus = Exclude<Status, "error">;
```

`ActiveStatus` becomes:

```text
"pending" | "success"
```

---

## `Extract`

`Extract<T, U>` keeps from `T` only the union members that are assignable to `U`.

```ts
type Status = "pending" | "success" | "error";

type SuccessfulStatus = Extract<Status, "success" | "error">;
```

`SuccessfulStatus` becomes:

```text
"success" | "error"
```

---

## `NonNullable`

`NonNullable<T>` removes `null` and `undefined` from a type.

```ts
type Value = string | null | undefined;

type RequiredValue = NonNullable<Value>;
```

`RequiredValue` becomes `string`.

---

## `Uppercase`

`Uppercase<T>` converts a string literal type to uppercase.

```ts
type Result = Uppercase<"hello">;
```

`Result` becomes:

```text
"HELLO"
```

---

## `Lowercase`

`Lowercase<T>` converts a string literal type to lowercase.

```ts
type Result = Lowercase<"HELLO">;
```

`Result` becomes:

```text
"hello"
```

---

## `Capitalize`

`Capitalize<T>` converts the first character of a string literal type to uppercase.

```ts
type Result = Capitalize<"hello">;
```

`Result` becomes:

```text
"Hello"
```

---

## `Uncapitalize`

`Uncapitalize<T>` converts the first character of a string literal type to lowercase.

```ts
type Result = Uncapitalize<"Hello">;
```

`Result` becomes:

```text
"hello"
```

---
