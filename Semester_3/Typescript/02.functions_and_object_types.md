# Functions & Object Types

## 1. Functions

TypeScript allows types to be specified for function parameters, return values, callbacks, and other parts of a function.

## Parameter & Return Types

One function can use every common parameter pattern and an explicit return type:

```ts
function createReport(
	title: string, // required parameter
	count: number, // required parameter
	subtitle?: string, // optional parameter
	prefix: string = "Report", // default parameter
	onDone: (message: string) => void, // callback parameter
	...tags: string[] // rest parameter
): string {
	// return type
	onDone(`${prefix}: ${title} (${count})`);
	return title;
}
```

Rules: optional and default parameters come after required ones; rest parameters must be last.

---

## Function Expressions

```ts
const add = function (a: number, b: number): number {
	return a + b;
};
```

## Arrow Functions

Arrow functions can also have typed parameters and return types.

```ts
const add = (a: number, b: number): number => {
	return a + b;
};
```

# 2. Object Types

Object types describe the structure of objects, including their properties and property types.

A single object type can combine every common property pattern — useful when modeling something like a user account:

```ts
let user: {
	id: number; // required property
	name: string; // required property
	readonly email: string; // readonly — set once, not reassigned
	phone?: string; // optional — can be omitted
	profile: {
		// nested object
		bio: string;
		city: string;
	};
	weeklyActivity: {
		// index signature — dynamic keys
		[day: string]: number;
	};
	getDisplayName(): string; // method definition
	sendNotification: (message: string) => void; // function property
} = {
	id: 1,
	name: "Satya",
	email: "satya@gmail.com",
	profile: {
		bio: "Full Stack Developer😎",
		city: "Surat",
	},
	weeklyActivity: {
		monday: 120,
		wednesday: 90,
	},
	getDisplayName() {
		return this.name;
	},
	sendNotification(message) {
		console.log(`Notify ${this.name}: ${message}`);
	},
};
```

Methods and function properties look similar, but methods get their own `this` binding; function properties are typed like regular function values.
