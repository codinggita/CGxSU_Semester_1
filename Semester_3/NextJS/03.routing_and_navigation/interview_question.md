# Routing and Navigation — Interview Questions

1. What is file-based routing in the App Router?

2. How does a nested folder structure like `app/products/[id]/page.tsx` map to URLs?

3. How do you read route `params` and `search params` in a Server Component page?

4. How do you read route `params` and `search params` in a Client Component page?

5. How are route groups like `(marketing)` different from normal folders in the URL?

6. What is the difference between catch-all `[...slug]` and optional catch-all `[[...slug]]` routes?

7. Why does Next.js prefer `<Link>` over a plain `<a>` tag for internal navigation?

8. What does `<Link prefetch>` do, and when might you turn prefetch off?

9. What is `usePathname()` used for, and where can it be used?

10. When should you use `useRouter()` for programmatic navigation, and which common methods does it provide?

11. A developer calls `router.push()` inside a Server Component. Why does it fail?

12. When should you use `redirect()` on the server instead of client-side navigation?

13. After a form submit, why might you use `router.replace()` instead of `router.push()`?

14. When should you use `redirect()` instead of `useRouter()`?

15. Why can't `router.push()` be directly used inside a Server Component?

16. What is the difference between `router.back()` and `router.replace()`?
