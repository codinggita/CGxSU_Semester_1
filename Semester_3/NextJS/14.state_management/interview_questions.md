10. When might fetching data in a Server Component be sufficient without TanStack Query?

13. What is the purpose of prefetching data on the server before rendering a page?

14. What do `dehydrate` and `HydrationBoundary` do when using TanStack Query with server-rendered pages?

17. What are a Zustand store, `set()`, and a store action?

18. How can multiple Client Components access and update the same Zustand store?

19. Why does a standard Zustand store created with `create()` not require a Provider?

20. What are the main differences between Zustand and Redux Toolkit?

21. Why do many developers choose Zustand for small and medium-sized React applications?

22. Is Redux Toolkit outdated? When might it still be a suitable choice?

23. Why should backend-owned product and order data generally not be stored as the source of truth in Zustand?

24. In an E-commerce application, where would you manage modal state, product data, cart state, and wishlist state?

25. Does Zustand automatically preserve its state after a page refresh?
