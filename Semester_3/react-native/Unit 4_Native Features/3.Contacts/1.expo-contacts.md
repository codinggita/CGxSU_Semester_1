# Contacts (`expo-contacts`)

## What is `expo-contacts`?

`expo-contacts` is an Expo SDK module that allows your React Native application to access the device's contacts.

Using this package, your application can:

- Request permission to access contacts
- Read contacts stored on the device
- Display contact information
- Search contacts
- Add new contacts
- Update existing contacts
- Delete contacts
- Export contacts as a VCF (vCard) file
- Open the native contact editor

It provides a simple API to interact with the phone's contact list without writing any native Android or iOS code.

---

# Why Do We Need Contacts?

Many modern mobile applications interact with the user's contacts to improve the user experience.

Instead of asking users to manually type names and phone numbers, applications can directly access saved contacts (after permission is granted).

Examples:

# Chapter 2 - Installation & Setup

Before we can access the device's contacts, we need to install the **expo-contacts** package and understand how to configure it.

---

# Step 1 - Install Expo Contacts

Install the official Expo Contacts package.

```bash
npx expo install expo-contacts
```

Why do we use `expo install` instead of `npm install`?

Because Expo installs the version that is compatible with your current Expo SDK.

Example:

```bash
npx expo install expo-contacts
```

instead of

```bash
npm install expo-contacts
```

This avoids version compatibility issues.

---

# Step 2 - Import the Package

Import the package into your component.

```js
import * as Contacts from "expo-contacts";
```

---

# Why Do We Use `* as Contacts`?

The package exports many functions.

Instead of importing them one by one, we import everything as **Contacts**.

For example:

```js
Contacts.requestPermissionsAsync();

Contacts.getContactsAsync();

Contacts.addContactAsync();

Contacts.updateContactAsync();

Contacts.removeContactAsync();

Contacts.presentFormAsync();

Contacts.writeContactToFileAsync();
```

Using:

```js
import * as Contacts from "expo-contacts";
```

keeps the code clean and organized.

# Function Used

Expo provides the following function:

```js
Contacts.requestPermissionsAsync()
```

This function displays the system permission dialog.

Example:

```

Allow

Don't Allow
```

The function waits for the user's response and returns a **Permission Object**.


Since the user takes time to respond,

```jsx
import { View, Button, Alert } from "react-native";
import * as Contacts from "expo-contacts";

        await Contacts.requestPermissionsAsync();

          "Success",
          "Permission Granted"

    } catch (error) {

    }

        alignItems:"center"

      />

    </View>

  );

}
```

# Checking Existing Permission

Instead of requesting permission every time,

we can first check the existing permission.

```jsx
const permission =
  await Contacts.getPermissionsAsync();

console.log(permission);
```

If permission is already granted,

there is no need to display the popup again.

Example:

```jsx
const permission =
  await Contacts.getPermissionsAsync();

if (permission.granted) {

  console.log("Already Granted");

} else {

  await Contacts.requestPermissionsAsync();

}
```

This is the recommended approach in production applications.

# Display Contact Names

```jsx
import { useState } from "react";
import { View, Button, Text } from "react-native";
import * as Contacts from "expo-contacts";

export default function App() {

  const [contacts, setContacts] = useState([]);

  const loadContacts = async () => {

    const permission =
      await Contacts.requestPermissionsAsync();

    if (!permission.granted) return;

    const { data } =
      await Contacts.getContactsAsync();

    setContacts(data);

  };

  return (

    <View
      style={{
        flex:1,
        justifyContent:"center",
        alignItems:"center",
        gap:10
      }}
    >

      <Button
        title="Load Contacts"
        onPress={loadContacts}
      />

      {contacts.map((contact) => (

        <Text key={contact.id}>
          {contact.name}
        </Text>

      ))}

    </View>

  );

}
```

# Using FlatList

When displaying many contacts,

`FlatList` is the recommended approach.

```jsx
<FlatList
  data={contacts}
  keyExtractor={(item) => item.id}
  renderItem={({ item }) => (
    <Text>{item.name}</Text>
  )}
/>
```

`FlatList` is faster and more memory-efficient than using `map()` for large lists.

Notice the use of:

```js

```

It prevents errors if a property doesn't exist.

---

# Why Use Optional Chaining?

Suppose a contact doesn't have an email.

 Wrong

```js
contact.emails[0].email
```

This may throw an error.

 Correct

```js
contact.emails?.[0]?.email
```

If the email doesn't exist,

the result is simply:

```js
undefined
```

instead of crashing the application.

# Chapter 7 - Sorting Contacts (`Contacts.SortTypes`)

In the previous chapter, we learned how to request specific contact fields using:

```js
Contacts.Fields
```

Now let's learn how to control the **order in which contacts are returned**.

Expo provides:

```js
Contacts.SortTypes
```

Sorting makes it easier for users to find contacts quickly.

---

# Why Do We Need Sorting?

Imagine your phone has 2,000 contacts.

Without sorting:

```
Rahul

Amit

Zoya

Ankit

Riya

Deepak
```

Finding a contact becomes difficult.

Instead, we sort them alphabetically.

```
Amit

Ankit

Deepak

Rahul

Riya

Zoya
```

This provides a much better user experience.

---

# What is `Contacts.SortTypes`?

`Contacts.SortTypes` tells Expo how contacts should be sorted before returning them.

Instead of manually sorting the array yourself,

Expo can return the contacts in the desired order.

---

# Syntax

```js
const { data } =
  await Contacts.getContactsAsync({

    sort:
      Contacts.SortTypes.FirstName,

});
```

---

# Basic Flow

```
Device Contacts

↓

Sort Option

↓

Expo Sorts Contacts

↓

Returns Sorted List
```

---

# Available Sort Types

Expo provides the following sorting options:

```js
Contacts.SortTypes.FirstName

Contacts.SortTypes.LastName

Contacts.SortTypes.UserDefault
```

Let's understand each one.

---

# Contacts.SortTypes.FirstName

```js
Contacts.SortTypes.FirstName
```

Sorts contacts alphabetically using the **first name**.

Example:

Before

```
Rahul Sharma

Amit Kumar

Deepak Singh

Ankit Verma
```

After

```
Amit Kumar

Ankit Verma

Deepak Singh

Rahul Sharma
```

---

# Example

```jsx
const { data } =
  await Contacts.getContactsAsync({

    sort:
      Contacts.SortTypes.FirstName,

});
```

---

# Contacts.SortTypes.LastName

```js
Contacts.SortTypes.LastName
```

Sorts contacts alphabetically using the **last name**.

Example:

Before

```
Rahul Sharma

Amit Kumar

Deepak Singh

Ankit Verma
```

After

```
Amit Kumar

Rahul Sharma

Deepak Singh

Ankit Verma
```

Because:

```
Kumar

↓

Sharma

↓

Singh

↓

Verma
```

---

# Example

```jsx
const { data } =
  await Contacts.getContactsAsync({

    sort:
      Contacts.SortTypes.LastName,

});
```

# Contacts.SortTypes.UserDefault

```js
Contacts.SortTypes.UserDefault
```

Uses the sorting preference configured by the user on their device.

Example:

Some users prefer:

```

```

Some users prefer:

```

```

Instead of forcing a sorting method,

Expo follows the user's system preference.

# Example


### Messaging Apps

Examples:

- WhatsApp
- Telegram

Usually use:



### Personal Contact Apps


Yes.

You can fetch contacts again using a different sorting option.

Example:

```jsx

  await Contacts.getContactsAsync({
```

or


If you don't specify the `sort` option,

Example:

```jsx

  await Contacts.getContactsAsync();
```

The order may vary between Android and iOS.

If your app requires a consistent order, always specify a sorting option.

- User's Contact Settings

Using:

# Chapter 8 - Displaying Contacts Using `FlatList`

In the previous chapter, we learned how to sort contacts using:

Almost every contact-based application displays contacts in a scrollable list.

We'll build a similar contact list using React Native's `FlatList`.

---

# Why Use FlatList?

Imagine your device has:

```
10 Contacts
```

Using:

```jsx
contacts.map(...)
```

works fine.

But what if the device has:

```
5,000 Contacts
```

Rendering all contacts at once can slow down your application.

Instead, React Native provides:

```jsx
<FlatList />
```

FlatList renders only the visible items.

Benefits:

- Better Performance
- Less Memory Usage
- Smooth Scrolling
- Recommended for Large Lists

---

# Basic Flow

```
Read Contacts

↓

Store in State

↓

Pass Data to FlatList

↓

Render Contact Card
```

---

# First Example

```jsx
import { useState } from "react";
import {
  View,
  Button,
  FlatList,
  Text,
} from "react-native";
import * as Contacts from "expo-contacts";

export default function App() {

  const [contacts, setContacts] = useState([]);

  const loadContacts = async () => {

    const permission =
      await Contacts.requestPermissionsAsync();

    if (!permission.granted) return;

    const { data } =
      await Contacts.getContactsAsync({

        fields: [
          Contacts.Fields.Name,
          Contacts.Fields.PhoneNumbers,
        ],

      });

    setContacts(data);

  };

  return (

    <View style={{ flex: 1 }}>

      <Button
        title="Load Contacts"
        onPress={loadContacts}
      />

      <FlatList
        data={contacts}
        keyExtractor={(item) => item.id}
        renderItem={({ item }) => (
          <Text
            style={{
              fontSize:18,
              padding:15
            }}
          >
            {item.name}
          </Text>
        )}
      />

    </View>

  );

}
```

This is an important question.

`addContactAsync()` looks very simple:

```js

```

But on Android, contact storage is connected to different accounts and storage locations.

For example:

```text
Google Account
Phone / Device
SIM
Other Contact Accounts
```

The actual available accounts depend on the Android device.

---

# Android Account Problem

Suppose the phone has:

```text
Default Contacts Account

↓

Google / Cloud
```

But the contact insertion is attempted against a local or SIM account.

Android can reject the operation.

You may see an error similar to:

```text
Cannot add contacts to local or SIM accounts
when default account is set to cloud
```

So the problem is not necessarily our JavaScript code.

The problem can be the Android device's contact-account configuration.

```js
import { View, Text, Button, FlatList, Image, Alert } from "react-native";

import * as Contacts from "expo-contacts";
import { useState } from "react";

export default function ContactScreen() {
  const [contacts, setContacts] = useState([]);

  // Get Contacts
  const getContacts = async () => {
    const permission = await Contacts.requestPermissionsAsync();

    if (!permission.granted) {
      Alert.alert(
        "Permission Denied",
        "Contact permission is required."
      );

      return;
    }

    const { data } = await Contacts.getContactsAsync({
      fields: [
        Contacts.Fields.PhoneNumbers,
        Contacts.Fields.Image,
      ],
    });

    setContacts(data);
  };

  // Delete Contact
  const handleDeleteContact = (contact) => {
    Alert.alert(
      "Delete Contact",
      `Are you sure you want to delete ${contact.name}?`,
      [
        {
          text: "Cancel",
          style: "cancel",
        },

        {
          text: "Delete",
          style: "destructive",

          onPress: async () => {
            try {
              await Contacts.removeContactAsync(contact.id);

              // Remove deleted contact from FlatList
              setContacts((previousContacts) =>
                previousContacts.filter(
                  (item) => item.id !== contact.id
                )
              );

              Alert.alert(
                "Success",
                "Contact deleted successfully"
              );
            } catch (error) {
              console.log("DELETE ERROR:", error);

              Alert.alert(
                "Error",
                "Unable to delete contact"
              );
            }
          },
        },
      ]
    );
  };

  // Render Contact
  const renderContact = ({ item }) => {
    const phone =
      item.phoneNumbers?.[0]?.number ||
      "No Phone Number";

    const firstLetter =
      item.name?.charAt(0)?.toUpperCase() || "?";

    return (
      <View
        style={{
          flexDirection: "row",
          alignItems: "center",
          padding: 15,
          marginBottom: 10,
          borderWidth: 1,
          borderColor: "#ddd",
          borderRadius: 12,
          backgroundColor: "white",
        }}
      >
        {/* Contact Image / Avatar */}

        {item.imageAvailable && item.image?.uri ? (
          <Image
            source={{ uri: item.image.uri }}
            style={{
              width: 60,
              height: 60,
              borderRadius: 30,
            }}
          />
        ) : (
          <View
            style={{
              width: 60,
              height: 60,
              borderRadius: 30,
              backgroundColor: "#4F46E5",
              justifyContent: "center",
              alignItems: "center",
            }}
          >
            <Text
              style={{
                fontSize: 26,
                fontWeight: "bold",
                color: "white",
              }}
            >
              {firstLetter}
            </Text>
          </View>
        )}

        {/* Contact Information */}

        <View
          style={{
            flex: 1,
            marginLeft: 15,
          }}
        >
          {/* Name */}

          <Text
            style={{
              fontSize: 18,
              fontWeight: "bold",
              color: "#222",
            }}
            numberOfLines={1}
          >
            {item.name || "Unknown Name"}
          </Text>

          {/* Phone */}

          <Text
            style={{
              marginTop: 6,
              fontSize: 14,
              color: "#666",
            }}
          >
            {phone}
          </Text>
        </View>

        {/* Delete Button */}

        <Button
          title="Delete"
          color="red"
          onPress={() => handleDeleteContact(item)}
        />
      </View>
    );
  };

  return (
    <View
      style={{
        flex: 1,
        padding: 20,
        paddingTop: 60,
      }}
    >
      <Button
        title="Get Contacts"
        onPress={getContacts}
      />

      <FlatList
        data={contacts}
        keyExtractor={(item) => item.id}
        renderItem={renderContact}
        contentContainerStyle={{
          marginTop: 20,
        }}
      />
    </View>
  );
}
```

# What is `Linking`?

`Linking` is a built-in React Native API that allows your application to communicate with external apps and device features using URLs.

Import it from React Native:

```js
import { Linking } from "react-native";
```

The most common function is:

```js
Linking.openURL()
```

Example:

```js
Linking.openURL("https://google.com");
```

This asks the operating system to open the URL using the appropriate application.

# Why Do We Need Linking?

Suppose our React Native application contains a contact:


```text

9876543210       📞
```

React Native itself does not need to build a dialer.

Instead, we tell the operating system:

```text
Open this telephone URL.
```

We do that with:

```js
Linking.openURL(`tel:${phone}`);
```


# What is `tel:`?

This is very important.

```text
tel:
```

is a URL scheme used to represent a telephone number.

Example:

```text

```

The operating system understands:

```text
tel:
```

as a request related to telephone calling.

Therefore:

```js

```

means:

```text
Open the phone application for this number.
```

# Better Error Handling

`Linking.openURL()` returns a Promise.

Therefore, we can use `async/await` and `try/catch`.

```js
const handleCall = async (phone) => {

  if (!phone) {
    Alert.alert(
      "No Phone Number",
      "This contact does not have a phone number."
    );

    return;
  }

  try {

    await Linking.openURL(`tel:${phone}`);

  } catch (error) {

    Alert.alert(
      "Error",
      "Unable to open the phone application."
    );

    console.log(error);
  }
};
```

This is a safer approach.

# Complete Contact App with Call Button

Now let's combine:

- `expo-contacts`
- Contact permission
- `getContactsAsync()`
- Phone numbers
- `FlatList`
- Contact images
- Avatar fallback
- Calling using `Linking`
- Delete contact
- Alerts
- Error handling

## Complete Code

```jsx
import {
  View,
  Text,
  Button,
  FlatList,
  Image,
  Alert,
  Linking,
} from "react-native";

import * as Contacts from "expo-contacts";

import { useState } from "react";

export default function ContactScreen() {

  const [contacts, setContacts] = useState([]);

  // Get Contacts
  const getContacts = async () => {

    try {

      const permission =
        await Contacts.requestPermissionsAsync();

      if (!permission.granted) {

        Alert.alert(
          "Permission Denied",
          "Contact permission is required."
        );

        return;
      }

      const { data } =
        await Contacts.getContactsAsync({

          fields: [
            Contacts.Fields.PhoneNumbers,
            Contacts.Fields.Image,
          ],

        });

      setContacts(data);

    } catch (error) {

      console.log(error);

      Alert.alert(
        "Error",
        "Unable to load contacts."
      );
    }
  };

  // Call Contact
  const handleCall = async (phone) => {

    if (!phone) {

      Alert.alert(
        "No Phone Number",
        "This contact does not have a phone number."
      );

      return;
    }

    try {

      const supported =
        await Linking.canOpenURL(
          `tel:${phone}`
        );

      if (supported) {

        await Linking.openURL(
          `tel:${phone}`
        );

      } else {

        Alert.alert(
          "Not Supported",
          "Phone calling is not available on this device."
        );
      }

    } catch (error) {

      console.log(error);

      Alert.alert(
        "Error",
        "Unable to open the phone application."
      );
    }
  };

  // Delete Contact
  const handleDelete = (item) => {

    Alert.alert(
      "Delete Contact",
      `Are you sure you want to delete this contact ${item.name}?`,
      [

        {
          text: "Cancel",
          style: "cancel",
        },

        {
          text: "Delete",
          style: "destructive",

          onPress: async () => {

            try {

              await Contacts.removeContactAsync(
                item.id
              );

              setContacts((prev) =>
                prev.filter(
                  (ele) => ele.id !== item.id
                )
              );

            } catch (error) {

              console.log(error);

              Alert.alert(
                "Error",
                "Unable to delete contact."
              );
            }
          },
        },

      ]
    );
  };

  // Render Contact
  const renderContact = ({ item }) => {

    const phone =
      item.phoneNumbers?.[0]?.number;

    const firstLetter =
      item.name?.charAt(0)?.toUpperCase() || "?";

    return (

      <View
        style={{
          flexDirection: "row",
          alignItems: "center",
          padding: 15,
          marginBottom: 10,
          borderWidth: 1,
          borderColor: "#ddd",
          borderRadius: 12,
          backgroundColor: "white",
        }}
      >

        {/* Contact Image / Avatar */}

        {item.imageAvailable && item.image?.uri ? (

          <Image
            source={{
              uri: item.image.uri,
            }}
            style={{
              width: 60,
              height: 60,
              borderRadius: 30,
            }}
          />

        ) : (

          <View
            style={{
              width: 60,
              height: 60,
              borderRadius: 30,
              backgroundColor: "#4F46E5",
              justifyContent: "center",
              alignItems: "center",
            }}
          >

            <Text
              style={{
                fontSize: 26,
                fontWeight: "bold",
                color: "white",
              }}
            >
              {firstLetter}
            </Text>

          </View>
        )}

        {/* Contact Information */}

        <View
          style={{
            flex: 1,
            marginLeft: 15,
          }}
        >

          <Text
            style={{
              fontSize: 18,
              fontWeight: "bold",
              color: "#222",
            }}
            numberOfLines={1}
          >
            {item.name || "Unknown Name"}
          </Text>

          <Text
            style={{
              marginTop: 6,
              fontSize: 14,
              color: "#666",
            }}
          >
            {phone || "No Phone Number"}
          </Text>

        </View>

        {/* Call Button */}

        <Button
          title="📞"
          onPress={() => handleCall(phone)}
        />

        {/* Delete Button */}

        <Button
          title="Delete"
          color="red"
          onPress={() => handleDelete(item)}
        />

      </View>
    );
  };

  return (

    <View
      style={{
        flex: 1,
        padding: 20,
        paddingTop: 60,
      }}
    >

      <Button
        title="Get Contacts"
        onPress={getContacts}
      />

      <FlatList
        data={contacts}
        keyExtractor={(item) => item.id}
        renderItem={renderContact}
        contentContainerStyle={{
          marginTop: 20,
        }}
      />

    </View>
  );
}
```

# What is a VCF File?

A **VCF (Virtual Contact File)**, also called a **vCard**, is a standard file format used to store contact information.

It can contain:

- Name
- Phone Number
- Email Address
- Company
- Job Title
- Website
- Birthday
- Notes

Example:

```
Rahul Sharma

↓

Export

↓

Rahul.vcf
```

This file can later be imported into another phone.

---

# Real-World Examples

- Google Contacts
- Samsung Contacts
- Phone Dialer
- CRM Applications
- Employee Management Systems

---

Exporting contacts is useful when:

- Creating backups
- Transferring contacts to another phone
- Sharing contacts
- Migrating to a new device

Example:

```

↓

Export Contacts

↓

↓

New Phone

↓

Import Contacts
```
