# Assignment 1 - Contact Explorer

This assignment is based on the concepts covered in the
**`expo-contacts`** module.


## Objective

Create a React Native application that works with the device's native
contacts.

Your application should allow users to:

-   Request contact permission
-   Get contact data
-   Sort contacts by First Name or Last Name
-   Search contacts by Name or Phone Number
-   Display contact images or avatars
-   Add new contacts
-   Delete contacts
-   Make phone calls
-   Refresh the contact list
-   Handle loading, empty, and error states


# Requirements

## 1. Contact Permission

Request permission before accessing contacts.

Use:

``` js
Contacts.requestPermissionsAsync()
```

### Requirements

-   Request Contacts permission.
-   Check whether permission is granted.
-   If permission is denied, show an `Alert`.
-   Do not access contacts without permission.
-   Handle errors properly.


# 2. Get Contact Data

After permission is granted, get contacts from the device.

Use:

``` js
Contacts.getContactsAsync()
```

Store the contacts in React state.


# 3. Sort Contacts

The user should be able to sort contacts using:

``` js
Contacts.SortTypes.FirstName
```

and:

``` js
Contacts.SortTypes.LastName
```

Provide two options:

``` text
First Name
Last Name
```

Selecting **First Name** should sort contacts according to their first
name.

Selecting **Last Name** should sort contacts according to their last
name.


# 4. Display Contacts

Use:

``` jsx
FlatList
```

Each contact card should display:

-   Profile image if available
-   Avatar if image is unavailable
-   Full name
-   First phone number
-   First email address if available
-   Delete button
-   Phone/Call icon

Use the contact's unique ID as the `FlatList` key.


# 5. Profile Image / Avatar

If the contact has an image, display it.

If the contact does not have an image, display an avatar using the first
letter of the contact's name.

Example:

``` text
Rajesh Ranjan
      ↓
      R
```

Make sure the application does not crash if:

-   Contact has no image
-   Contact has no name


# 6. Search Contacts

Add a search bar.

Example:

``` text
Search by name or phone number...
```

Search must work in **real time**.

Use:

``` jsx
<TextInput />
```

and update the search value using:

``` js
onChangeText
```

### Search by Name

Users should be able to search contacts by name.

Example:

``` text
Search: Rahul
```

Search must be **case-insensitive**.

### Search by Phone Number

Users should also be able to search using a phone number.

Example:

``` text
Search: 9876
```

This should find contacts whose phone number contains `9876`.

The final search should support:

``` text
Name OR Phone Number
```


# 7. No Search Results

If no contact matches the search, display:

``` text
No Contacts Found
```

This should update automatically while the user types.


# 8. Contact Count

Display the total number of contacts.

Example:

``` text
Total Contacts : 143
```

The count should update after:

-   Adding a contact
-   Deleting a contact
-   Refreshing contacts


# 9. Loading State

While contacts are loading, display:

``` text
Loading Contacts...
```

The loading state should be shown during:

-   Initial contact loading
-   Refreshing contacts


# 10. Add Contact

Create an:

``` text
Add Contact
```

button.

The user should be able to add a new contact containing at least:

-   First Name
-   Last Name
-   Phone Number
-   Email

## Use `addContactAsync()`

Try to add the contact using:

``` js
Contacts.addContactAsync()
```

The contact should be created using a Contact Object.

## Fallback: `presentFormAsync()`

If `addContactAsync()` does not work on the device, use:

``` js
Contacts.presentFormAsync()
```

to open the native Contacts form.

After the contact is successfully added, refresh the contact list.


# 11. Refresh Contacts

Create a:

``` text
Refresh
```

button.

When the user presses Refresh:

-   Reload contacts from the device.
-   Update the contact list.
-   Update the contact count.
-   Apply the selected sorting.
-   Keep the current application state consistent.

Try to reuse your existing contact-loading function instead of
duplicating code.


# 12. Delete Contact

Every contact card should have a:

``` text
Delete
```

button.

Use:

``` js
Contacts.removeContactAsync()
```

The selected contact's unique:

``` js
contact.id
```

should be used for deletion.

## Delete Confirmation

Do not delete a contact immediately.

Show a confirmation alert first.

Example:

``` text
Delete Contact

Are you sure you want to delete
Rajesh Ranjan?

Cancel        Delete
```

The Delete option should be a destructive action.

After deletion:

-   Update the contact list.
-   Update the contact count.
-   Keep the UI synchronized with the device contacts.

# 13. Phone / Call Icon

Beside the Delete button, add a phone/call icon.

Example:

``` text
Delete    📞
```

You may use:

``` js
Ionicons
```

or another icon library available in your project.


# 14. Make a Phone Call

When the user taps the phone icon, open the device's phone application.

Use React Native:

``` js
Linking
```

Use the:

``` text
tel:
```

URL scheme.

Pressing the call icon should open the phone application for that
number.

## Contact Without Phone Number

If the contact has no phone number, show:

``` text
No Phone Number

This contact does not have a phone number.
```

Do not attempt to open an invalid `tel:` URL.


# 15. Error Handling

Use `try...catch` for asynchronous operations.

Handle errors for:

-   Requesting permission
-   Loading contacts
-   Adding contacts
-   Opening the native contact form
-   Deleting contacts
-   Making phone calls

Display meaningful error messages using `Alert`.

# Bonus Features

These features are optional.

For additional practice, implement one or more:

-   Edit existing contact
-   Show all phone numbers
-   Show all email addresses
-   Clear search button
-   Favorite contacts
-   Dark mode
-   Animations

``` bash
npx expo install expo-contacts
```

``` js
import React, { useEffect, useMemo, useState } from "react";

import {
  ActivityIndicator,
  Alert,
  FlatList,
  Image,
  Linking,
  Pressable,
  StatusBar,
  StyleSheet,
  Text,
  TextInput,
  View,
} from "react-native";
import { SafeAreaView } from "react-native-safe-area-context";

import * as Contacts from "expo-contacts";

import { Ionicons } from "@expo/vector-icons";

// Main Component

export default function ContactScreen() {
  const [contacts, setContacts] = useState([]);

  const [search, setSearch] = useState("");

  const [sortType, setSortType] = useState(Contacts.SortTypes.FirstName);

  const [loading, setLoading] = useState(false);

  const [permissionGranted, setPermissionGranted] = useState(false);

  // Request Permission

  const requestContactPermission = async () => {
    try {
      const permission = await Contacts.requestPermissionsAsync();

      if (!permission.granted) {
        setPermissionGranted(false);

        Alert.alert(
          "Permission Required",
          "Please allow Contacts permission to use Contact Explorer.",
        );

        return false;
      }

      setPermissionGranted(true);

      return true;
    } catch (error) {
      console.log("Permission Error:", error);

      Alert.alert(
        "Error",
        "Something went wrong while requesting contact permission.",
      );

      return false;
    }
  };

  // Get Contacts

  const getContacts = async (selectedSort = sortType) => {
    try {
      setLoading(true);

      // Request permission
      const permission = await Contacts.requestPermissionsAsync();

      if (!permission.granted) {
        setPermissionGranted(false);

        Alert.alert("Permission Required", "Contacts permission is required.");

        return;
      }

      setPermissionGranted(true);

      // Get contacts
      const response = await Contacts.getContactsAsync({
        fields: [
          Contacts.Fields.Name,
          Contacts.Fields.PhoneNumbers,
          Contacts.Fields.Emails,
          Contacts.Fields.Image,
        ],

        sort: selectedSort,
      });

      // Store contacts
      setContacts(response.data);
    } catch (error) {
      console.log("Get Contacts Error:", error);

      Alert.alert("Error", "Unable to load contacts.");
    } finally {
      setLoading(false);
    }
  };

  // Initial Load

  useEffect(() => {
    getContacts();
  }, []);

  // Change Sorting

  const handleSortChange = async (type) => {
    setSortType(type);

    await getContacts(type);
  };

  // Filter Contacts
  // Search by Name OR Phone Number

  const filteredContacts = useMemo(() => {
    const searchText = search.trim().toLowerCase();

    if (!searchText) {
      return contacts;
    }

    return contacts.filter((contact) => {
      // Search by name
      const nameMatch = contact.name?.toLowerCase().includes(searchText);

      // Search by phone number
      const phoneMatch = contact.phoneNumbers?.some((phone) =>
        phone.number?.toLowerCase().includes(searchText),
      );

      return nameMatch || phoneMatch;
    });
  }, [contacts, search]);

  // Call Contact

  const handleCall = async (phone) => {
    if (!phone) {
      Alert.alert(
        "No Phone Number",
        "This contact does not have a phone number.",
      );

      return;
    }

    try {
      const phoneUrl = `tel:${phone}`;

      const supported = await Linking.canOpenURL(phoneUrl);

      if (!supported) {
        Alert.alert(
          "Unavailable",
          "Phone calling is not available on this device.",
        );

        return;
      }

      await Linking.openURL(phoneUrl);
    } catch (error) {
      console.log("Call Error:", error);

      Alert.alert("Error", "Unable to open the phone application.");
    }
  };

  // Delete Contact

  const handleDelete = (contact) => {
    Alert.alert(
      "Delete Contact",
      `Are you sure you want to delete ${contact.name || "this contact"}?`,
      [
        {
          text: "Cancel",
          style: "cancel",
        },

        {
          text: "Delete",
          style: "destructive",

          onPress: async () => {
            try {
              setLoading(true);

              await Contacts.removeContactAsync(contact.id);

              Alert.alert("Success", "Contact deleted successfully.");

              // Reload contacts
              await getContacts();
            } catch (error) {
              console.log("Delete Contact Error:", error);

              Alert.alert("Error", "Unable to delete contact.");
            } finally {
              setLoading(false);
            }
          },
        },
      ],
    );
  };

  // Add Contact

  const handleAddContact = async () => {
    try {
      const permission = await Contacts.requestPermissionsAsync();

      if (!permission.granted) {
        Alert.alert("Permission Denied", "Contact permission is required.");

        return;
      }

      const contact = {
        [Contacts.Fields.FirstName]: "",
        [Contacts.Fields.LastName]: "",

        phoneNumbers: [
          {
            label: "mobile",
            number: "",
          },
        ],

        emails: [
          {
            label: "email",
            email: "",
          },
        ],
      };

      await Contacts.presentFormAsync(null, contact, {
        isNew: true,
      });

      await getContacts();
    } catch (error) {
      console.log(" CONTACT ERROR:", error);

      Alert.alert("Error", "Unable to open contact form.");
    }
  };

  // Render Avatar

  const renderAvatar = (contact) => {
    const firstLetter = contact.name?.trim()?.charAt(0)?.toUpperCase() || "?";

    // Contact has image
    if (contact.imageAvailable && contact.image?.uri) {
      return (
        <Image
          source={{
            uri: contact.image.uri,
          }}
          style={styles.profileImage}
        />
      );
    }

    // Contact doesn't have image
    return (
      <View style={styles.avatar}>
        <Text style={styles.avatarText}>{firstLetter}</Text>
      </View>
    );
  };

  // Contact Card

  const renderContact = ({ item }) => {
    const phone = item.phoneNumbers?.[0]?.number || null;

    const email = item.emails?.[0]?.email || null;

    return (
      <View style={styles.contactCard}>
        {/* Left Section */}
        <View style={styles.avatarContainer}>{renderAvatar(item)}</View>

        {/* Middle Section */}
        <View style={styles.contactInfo}>
          <Text style={styles.contactName} numberOfLines={1}>
            {item.name || "Unknown Contact"}
          </Text>

          <View style={styles.infoRow}>
            <Ionicons name="call-outline" size={15} color="#64748b" />

            <Text style={styles.infoText} numberOfLines={1}>
              {phone || "No Phone Number"}
            </Text>
          </View>

          <View style={styles.infoRow}>
            <Ionicons name="mail-outline" size={15} color="#64748b" />

            <Text style={styles.infoText} numberOfLines={1}>
              {email || "No Email Address"}
            </Text>
          </View>
        </View>

        {/* Actions */}
        <View style={styles.actions}>
          {/* Delete */}
          <Pressable
            style={[styles.actionButton, styles.deleteButton]}
            onPress={() => handleDelete(item)}
          >
            <Ionicons name="trash-outline" size={20} color="#dc2626" />
          </Pressable>

          {/* Call */}
          <Pressable
            style={[styles.actionButton, styles.callButton]}
            onPress={() => handleCall(phone)}
          >
            <Ionicons name="call" size={20} color="#16a34a" />
          </Pressable>
        </View>
      </View>
    );
  };

  // Permission Screen

  if (!permissionGranted && !loading) {
    return (
      <SafeAreaView style={styles.container}>
        <StatusBar barStyle="dark-content" backgroundColor="#f8fafc" />

        <View style={styles.permissionContainer}>
          <View style={styles.permissionIcon}>
            <Ionicons name="people-outline" size={55} color="#2563eb" />
          </View>

          <Text style={styles.permissionTitle}>Contact Explorer</Text>

          <Text style={styles.permissionDescription}>
            This application needs access to your contacts to display, search
            and manage your contacts.
          </Text>

          <Pressable
            style={styles.permissionButton}
            onPress={async () => {
              const granted = await requestContactPermission();

              if (granted) {
                await getContacts();
              }
            }}
          >
            <Ionicons name="lock-open-outline" size={20} color="#ffffff" />

            <Text style={styles.permissionButtonText}>
              Grant Contact Permission
            </Text>
          </Pressable>
        </View>
      </SafeAreaView>
    );
  }

  // Main UI

  return (
    <SafeAreaView style={styles.container}>
      <StatusBar barStyle="dark-content" backgroundColor="#f8fafc" />

      {/* Header */}
      <View style={styles.header}>
        <View>
          <Text style={styles.title}>Contact Explorer</Text>

          <Text style={styles.subtitle}>Manage your contacts</Text>
        </View>

        {/* Add Contact */}
        <Pressable style={styles.addButton} onPress={handleAddContact}>
          <Ionicons name="person-add-outline" size={22} color="#ffffff" />
        </Pressable>
      </View>

      {/* Search */}
      <View style={styles.searchContainer}>
        <Ionicons name="search-outline" size={22} color="#64748b" />

        <TextInput
          style={styles.searchInput}
          placeholder="Search by name or phone..."
          placeholderTextColor="#94a3b8"
          value={search}
          onChangeText={setSearch}
          autoCapitalize="none"
        />

        {search.length > 0 && (
          <Pressable onPress={() => setSearch("")}>
            <Ionicons name="close-circle" size={21} color="#94a3b8" />
          </Pressable>
        )}
      </View>

      {/* Stats */}
      <View style={styles.statsCard}>
        <View style={styles.statItem}>
          <Text style={styles.statValue}>{contacts.length}</Text>

          <Text style={styles.statLabel}>Total Contacts</Text>
        </View>

        <View style={styles.statDivider} />

        <View style={styles.statItem}>
          <Text style={styles.statValue}>{filteredContacts.length}</Text>

          <Text style={styles.statLabel}>Showing</Text>
        </View>
      </View>

      {/* Sort */}
      <View style={styles.sortSection}>
        <Text style={styles.sortTitle}>Sort By</Text>

        <View style={styles.sortButtons}>
          <Pressable
            style={[
              styles.sortButton,

              sortType === Contacts.SortTypes.FirstName &&
                styles.activeSortButton,
            ]}
            onPress={() => handleSortChange(Contacts.SortTypes.FirstName)}
          >
            <Text
              style={[
                styles.sortButtonText,

                sortType === Contacts.SortTypes.FirstName &&
                  styles.activeSortButtonText,
              ]}
            >
              First Name
            </Text>
          </Pressable>

          <Pressable
            style={[
              styles.sortButton,

              sortType === Contacts.SortTypes.LastName &&
                styles.activeSortButton,
            ]}
            onPress={() => handleSortChange(Contacts.SortTypes.LastName)}
          >
            <Text
              style={[
                styles.sortButtonText,

                sortType === Contacts.SortTypes.LastName &&
                  styles.activeSortButtonText,
              ]}
            >
              Last Name
            </Text>
          </Pressable>
        </View>
      </View>

      {/* Loading */}
      {loading && contacts.length === 0 ? (
        <View style={styles.loadingContainer}>
          <ActivityIndicator size="large" color="#2563eb" />

          <Text style={styles.loadingText}>Loading Contacts...</Text>
        </View>
      ) : (
        <FlatList
          data={filteredContacts}
          keyExtractor={(item) => item.id}
          renderItem={renderContact}
          showsVerticalScrollIndicator={false}
          contentContainerStyle={
            filteredContacts.length === 0
              ? styles.emptyList
              : styles.listContent
          }
          ListEmptyComponent={() => (
            <View style={styles.emptyContainer}>
              <View style={styles.emptyIcon}>
                <Ionicons
                  name={search.trim() ? "search-outline" : "people-outline"}
                  size={45}
                  color="#94a3b8"
                />
              </View>

              <Text style={styles.emptyTitle}>No Contacts Found</Text>

              <Text style={styles.emptyDescription}>
                {search.trim()
                  ? "Try searching with another name or phone number."
                  : "There are no contacts available on your device."}
              </Text>
            </View>
          )}
        />
      )}

      {/* Floating Add Button */}
      <Pressable style={styles.floatingButton} onPress={handleAddContact}>
        <Ionicons name="add" size={32} color="#ffffff" />
      </Pressable>
    </SafeAreaView>
  );
}
```
