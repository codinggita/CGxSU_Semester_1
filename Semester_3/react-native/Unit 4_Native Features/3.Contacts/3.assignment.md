# Assignment 2 - Smart Contact Manager

Build a professional **Smart Contact Manager** using React Native, Expo, and **`expo-contacts`**.

---

# Objective

Create a complete Contact Management application that allows users to:

- Request contact permission
- Load real device contacts
- Display detailed contact information
- Search by Name, Phone Number, or Email
- Sort contacts
- Filter contacts
- Add contacts using the native contact form
- Edit existing contacts
- Delete contacts
- Export contacts
- Display contact statistics
- Pull to refresh
- Handle loading, empty, and error states
- Keep the UI synchronized after every contact operation

The application must work with **real device contacts**.

---

# Requirements

## 1. Contact Permission

Request Contacts permission before performing any contact operation.

Use:

```js
Contacts.requestPermissionsAsync()
```

### Requirements

- Request contact permission.
- Check whether permission is granted.
- Show an `Alert` when permission is denied.
- Do not load or modify contacts without permission.
- Handle permission errors using `try...catch`.

---

# 2. Load Contacts

Fetch contacts using:

```js
Contacts.getContactsAsync()
```

Request the following fields:

```js
Contacts.Fields.Name
Contacts.Fields.PhoneNumbers
Contacts.Fields.Emails
Contacts.Fields.Image
Contacts.Fields.Company
Contacts.Fields.JobTitle
```

Sort the initial contact list using:

```js
Contacts.SortTypes.UserDefault
```

### Requirements

- Store contacts in React state.
- Store only the data required by the application.
- Handle loading state.
- Handle errors.
- Reload contacts after Add, Edit, Delete, and Refresh operations.

---

# 3. Display Contact Cards

Display contacts using:

```jsx
FlatList
```

Each contact card should display:

- Profile Image / Avatar
- Full Name
- Company
- Job Title
- First Phone Number
- First Email Address
- Edit action
- Delete action

Use:

```js
contact.id
```

as the unique key for the `FlatList`.

---

# 4. Profile Image / Avatar

If the contact has a profile image, display it.

If no image is available, display an avatar using the first letter of the contact's name.

Example:

```text
Rajesh Ranjan
      ↓
      R
```

### Handle Missing Data

Your application must not crash when:

- Contact has no image
- Contact has no phone number
- Contact has no email
- Contact has no company
- Contact has no job title
- Contact has no name

Display suitable fallback text where necessary.

For example:

```text
No Phone Number
No Email Address
No Company
No Job Title
```

---

# 5. Search Contacts

Add a search bar at the top.

Example:

```text
Search name, phone or email...
```

Search must update **in real time** while the user types.

The search should support:

```text
Name
OR
Phone Number
OR
Email Address
```

---

## Search by Name

Example:

```text
Search: Rahul
```

Possible results:

```text
Rahul Sharma
Rahul Kumar
Rahul Verma
```

Search should be case-insensitive.

---

## Search by Phone Number

Example:

```text
Search: 9876
```

The application should find contacts whose phone number contains:

```text
9876
```

---

## Search by Email

Example:

```text
Search: gmail
```

The application should find contacts containing:

```text
@gmail.com
```

---

# 6. Advanced Filtering

Add filtering functionality in addition to the search bar.

At minimum, provide these filters:

```text
All
With Phone
With Email
```

### Expected Behavior

Selecting:

```text
All
```

shows every contact matching the search.

Selecting:

```text
With Phone
```

shows only contacts that have at least one phone number.

Selecting:

```text
With Email
```

shows only contacts that have at least one email address.

### Important

Search and filters should work together.

For example:

```text
Search: Rahul
Filter: With Phone
```

should display only contacts that:

1. Match "Rahul"
2. Have a phone number

---

# 7. Sort Contacts

Provide sorting options.

At minimum:

```text
First Name
Last Name
Default
```

Use the appropriate Expo Contacts sort types:

```js
Contacts.SortTypes.FirstName

Contacts.SortTypes.LastName

Contacts.SortTypes.UserDefault
```

### Expected Behavior

The selected sorting method should immediately affect the displayed list.

Sorting should continue to work together with:

- Search
- Filters
- Refresh

---

# 8. Add New Contact

Create a Floating Action Button (FAB).

Example:

```text
        ┌─────┐
        │  +  │
        └─────┘
```

When the user presses the FAB, open the native contact form.

Use:

```js
Contacts.presentFormAsync(null)
```

### Requirements

- Open the native contact creation form.
- Allow the user to enter contact information.
- Do not create fake/local-only contact data.
- Refresh the contact list after the form is completed.
- Update statistics after adding a contact.

---

# 9. Edit Contact

Each contact card should contain:

```text
Edit
```

When the user presses Edit, open the native contact editor.

Use:

```js
Contacts.presentFormAsync(contact.id)
```

### Requirements

- Pass the selected contact's ID.
- Open the native contact editor.
- Allow the user to modify contact information.
- Refresh the contact list after editing.
- Recalculate statistics after editing.

---

# 10. Delete Contact

Each contact card should contain:

```text
Delete
```

Use:

```js
Contacts.removeContactAsync(contact.id)
```

### Requirements

- Show a confirmation dialog before deletion.
- Pass the correct contact ID.
- Delete the contact from the device.
- Refresh the contact list.
- Update contact statistics.

### Confirmation Example

```text
Delete Contact

Are you sure you want to delete
Rajesh Ranjan?

Cancel       Delete
```

The Delete action should be treated as destructive.

---

# 11. Export Contact

Each contact card should contain:

```text
Export
```

Export the selected contact using:

```js
Contacts.writeContactToFileAsync(contact.id)
```

The function creates a contact file, such as a vCard/VCF file.

### Requirements

After exporting:

- Display the exported file URI using `Alert`.
- Also log the URI using `console.log()`.
- Handle export errors.
- Make sure the correct contact ID is exported.

---

# 12. Contact Statistics

Display contact statistics at the top of the screen.

Example:

```text
Total Contacts : 152

Contacts With Phone : 140

Contacts With Email : 86

Contacts Without Phone : 12
```

Calculate the values from the loaded contact data.

### Required Statistics

- Total Contacts
- Contacts With Phone
- Contacts With Email
- Contacts Without Phone

### Statistics Must Update

Statistics should be recalculated after:

- Adding a contact
- Editing a contact
- Deleting a contact
- Refreshing contacts

Do not hardcode these numbers.

---

# 13. Pull To Refresh

Implement:

```jsx
RefreshControl
```

inside the `FlatList`.

Users should be able to pull down on the contact list to reload contacts.

---

# 14. Loading State

Display:

```text
Loading Contacts...
```

when contacts are initially loading.

For pull-to-refresh, use the refresh indicator instead of unnecessarily replacing the whole list with a loading message.

Handle loading states separately where appropriate.

---

# 15. Empty State

If there are no contacts, display:

```text
No Contacts Available

Tap + to add your first contact.
```

If the user has contacts but their search/filter produces no results, display a different message such as:

```text
No Matching Contacts

Try another search or change the filter.
```

### Important

Differentiate between:

```text
No contacts exist
```

and:

```text
Contacts exist but no results match
```

---

The following features must work together:

```text
Search
   +
Filter
   +
Sort
```

Example:


2. Apply the selected filter.

Use:

```js
contact.id
```

to identify the selected contact.

---

# 18. Error Handling

Use `try...catch` for asynchronous operations.

Handle errors for:

- Requesting permission
- Loading contacts
- Adding contacts
- Editing contacts
- Deleting contacts
- Exporting contacts
- Refreshing contacts

Show meaningful error messages using `Alert`.

Do not silently ignore errors.
