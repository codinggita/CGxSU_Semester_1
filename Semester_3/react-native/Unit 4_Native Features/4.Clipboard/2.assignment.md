# Assignment 1 - Clipboard Utility App

This assignment is based on the concepts covered in the **`expo-clipboard`** module.

---

## Objective

Create a React Native application that works with the device clipboard using **Expo SDK 54**.

Your application should allow users to:

- Enter text
- Copy text to the clipboard
- Check whether text exists in the clipboard
- Paste text from the clipboard
- Copy a URL
- Check whether an image exists in the clipboard
- Paste an image from the clipboard
- Display the pasted image
- Display image dimensions
- Detect clipboard changes
- Detect clipboard content type
- Properly remove the clipboard listener
- Handle loading and error states

---

# 1. Installation

Install `expo-clipboard`:

```bash
npx expo install expo-clipboard
```

Example UI:

```text

----------------------------------

[ Hello React Native........... ]

[ Copy Text ]

[ Paste Text ]

```

Use `useState` to manage the entered text.

# 3. Copy Text

Create a **Copy Text** button.

When the user presses it, use:

```js
Clipboard.setStringAsync()
```

Example:

```js
await Clipboard.setStringAsync(text);
```

### Validation

If the input is empty, show:

```text
Please enter some text.
```

using `Alert`.

After successful copying, show:

```text
Text copied successfully.
```

# 4. Check Clipboard

Create a button:

```text
[ Check Clipboard ]
```

Use:

```js

```

If text exists:

```text

```



3. Display the clipboard text in the application.

```text

----------------------------------
```

# 6. Copy URL

Create a predefined URL:

```js
const url = "https://example.com";
```

Add:

```text
[ Copy URL ]
```

For this assignment, use:

```js
Clipboard.setStringAsync(url);
```

After copying, display:

```text
URL copied successfully.
```

> Note: `setUrlAsync()` is iOS-specific in Expo SDK 54. Use `setStringAsync()` for cross-platform URL copying in this assignment.

# 8. Paste Image

Create:

```text
[ Paste Image ]
```

When pressed:

1. Check using `hasImageAsync()`.
2. If an image exists, use `getImageAsync()`.
3. Request the image as PNG.
4. Display the image.

Example:

```js
const image = await Clipboard.getImageAsync({
  format: "png",
});
```

Display the image using React Native's:

```jsx
<Image />
```

# 10. Clipboard Change Listener

Your application should automatically detect when the clipboard changes.

Use:

```js
Clipboard.addClipboardListener()
```

The listener should detect:

```text
Plain Text
Image
URL
HTML
```

Use:

```js
event.contentTypes
```

to determine the content type.

# 12. Read Text When Clipboard Changes

If the listener detects:

```js
Clipboard.ContentType.PLAIN_TEXT
```

use:

```js
Clipboard.getStringAsync()
```

to retrieve the actual text.

Display it on the screen.

Example:

```text
----------------------------------

Latest Clipboard Text

Hello React Native

----------------------------------
```

---

# 13. Listener Cleanup

You must remove the listener when the component unmounts.

Use:

```js
useEffect(() => {

  const subscription =
    Clipboard.addClipboardListener(
      callback
    );

  return () => {

    subscription.remove();

  };

}, []);
```

Do not leave the listener running after the screen is removed.

---

# 14. Loading State

When retrieving an image, display a loading state.

Example:

```text
[ Loading Image... ]
```

instead of:

```text
[ Paste Image ]
```

Use `useState()` to manage the loading state.

---

# 15. Error Handling

Clipboard operations are asynchronous.

Use:

```js
try {

  // Clipboard operation

} catch (error) {

  // Handle error

}
```

If something goes wrong, display an appropriate `Alert`.

Example:

```text
Error

Unable to read clipboard.
```
