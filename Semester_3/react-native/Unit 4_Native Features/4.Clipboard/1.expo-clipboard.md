# Clipboard (`expo-clipboard`)

# Chapter 1 - What is a Clipboard?


The **clipboard** is temporary storage provided by the operating system that allows users to copy and paste content.

For example:

```text
User selects text

        ↓

      Copy

        ↓

    Clipboard

        ↓

      Paste

        ↓

Another App / Same App
```

A user can copy:

* Text
* URLs
* Codes
* Phone Numbers
* Email Addresses
* Other supported content

# Main Clipboard Operations

The basic clipboard workflow consists of three important operations:

```text
Write

↓

Read

↓

Check
```

Expo provides:

```js
Clipboard.setStringAsync()
```

to write text.

```js
Clipboard.getStringAsync()
```

to read text.

```js
Clipboard.hasStringAsync()
```

to check whether text exists.

---

# 1. `setStringAsync()`

This method writes a string into the clipboard.

Syntax:

```js
await Clipboard.setStringAsync(text);
```

Example:

```js
await Clipboard.setStringAsync("Hello World");
```

Now:

```text
Hello World
```

is stored in the clipboard.

The SDK 54 API accepts a string and returns a Promise. On Android and iOS, the Promise resolves to `true`; on Web, it indicates whether the string was successfully saved.

---

# 2. `getStringAsync()`

This method reads text from the clipboard.

Syntax:

```js
const text =
  await Clipboard.getStringAsync();
```

Example:

```js
const text =
  await Clipboard.getStringAsync();

console.log(text);
```

If the clipboard contains:

```text
Hello World
```

the result will be:

```js
"Hello World"
```

---

# 3. `hasStringAsync()`

This method checks whether the clipboard currently contains text.

Syntax:

```js
const hasText =
  await Clipboard.hasStringAsync();
```

It returns:

```js
true
```

or:

```js
false
```

For example:

```js
const hasText =
  await Clipboard.hasStringAsync();

if (hasText) {

  console.log("Clipboard contains text");

} else {

  console.log("Clipboard is empty");

}
```

SDK 54 documents that this returns `true` for both plain text and rich text such as HTML.

# Basic Clipboard Flow

The simplest clipboard application looks like this:

```text
User enters text

↓

setStringAsync()

↓

Text copied

↓

getStringAsync()

↓

Read copied text
```

# Basic Example

```jsx
import { useState } from "react";
import {
  View,
  Text,
  TextInput,
  Button,
} from "react-native";

import * as Clipboard from "expo-clipboard";

export default function App() {

  const [text, setText] = useState("");
  const [clipboardText, setClipboardText] =
    useState("");

  const copyText = async () => {

    await Clipboard.setStringAsync(text);

  };

  const pasteText = async () => {

    const value =
      await Clipboard.getStringAsync();

    setClipboardText(value);

  };

  return (

    <View
      style={{
        flex: 1,
        padding: 20,
        justifyContent: "center",
      }}
    >

      <TextInput
        placeholder="Enter text"
        value={text}
        onChangeText={setText}
        style={{
          borderWidth: 1,
          padding: 12,
          marginBottom: 10,
        }}
      />

      <Button
        title="Copy"
        onPress={copyText}
      />

      <Button
        title="Paste"
        onPress={pasteText}
      />

      <Text
        style={{
          marginTop: 20,
          fontSize: 18,
        }}
      >
        {clipboardText}
      </Text>

    </View>

  );

}
```

---

# Understanding the Example

We have two states:

```js
const [text, setText] = useState("");
```

This stores the text entered by the user.

And:

```js
const [clipboardText, setClipboardText] =
  useState("");
```

This stores the text retrieved from the clipboard.

# Chapter 2 - Copying Text with `setStringAsync()`

In the previous chapter, we learned what the clipboard is and how `expo-clipboard` works.

```js
Clipboard.setStringAsync()
```

This method is used to **copy text to the device clipboard**.

---

# What Does `setStringAsync()` Do?

The method takes a string and places it into the system clipboard.

```js
await Clipboard.setStringAsync(text);
```

For example:

```js
await Clipboard.setStringAsync("Hello World");
```

After this runs, the user can paste:

```text
Hello World
```

into another application.

---

# Basic Flow

```text

↓

Press Copy

↓

setStringAsync()

↓

Text goes to system clipboard

↓

User can Paste
```

```js
await Clipboard.setStringAsync(text);
```

Example:

```js
const copyText = async () => {

  await Clipboard.setStringAsync(
    "Hello World"

```

# Reusable Copy Button

Instead of writing the same function repeatedly, we can create a reusable component.

```jsx
import { Button } from "react-native";
import * as Clipboard from "expo-clipboard";

const CopyButton = ({ text }) => {

  const handleCopy = async () => {

    if (!text) {
      return;
    }

    await Clipboard.setStringAsync(text);

  };

  return (

    <Button
      title="Copy"
      onPress={handleCopy}
    />

  );

};

export default CopyButton;
```

Now we can use it anywhere:

```jsx
<CopyButton

/>
```

Or:

```jsx

  text="rahul@gmail.com"
/>
```

Or:

```jsx

  text="https://example.com"
/>
```

# Reusable Copy Button with Alert

```jsx
import {
  Button,
  Alert,
} from "react-native";

import * as Clipboard from "expo-clipboard";

const CopyButton = ({ text }) => {

  const handleCopy = async () => {

    if (!text?.trim()) {

      Alert.alert(
        "Nothing to Copy",
        "There is no text available."
      );

      return;

    }

    try {

      await Clipboard.setStringAsync(text);

      Alert.alert(
        "Copied!",
        "Text copied to clipboard."
      );

    } catch (error) {

      Alert.alert(
        "Error",
        "Unable to copy text."
      );

      console.log(error);

    }

  };

  return (

    <Button
      title="Copy"
      onPress={handleCopy}
    />

  );

};

export default CopyButton;
```

# Checking the Input Before Copying

A good copy function should validate the value.

```js
const copyText = async () => {

  if (
    typeof text !== "string" ||
    !text.trim()
  ) {

    return;

  }

  await Clipboard.setStringAsync(text);

};
```

This prevents unexpected values from being copied.

# Error Handling

Clipboard operations are asynchronous.

Therefore, use:

```js
try...catch
```

Example:

```js
const copyText = async () => {

  try {

    await Clipboard.setStringAsync(text);

    console.log("Copied successfully");

  } catch (error) {

    console.log(
      "Copy failed:",
      error
    );

  }

};
```

# Chapter 3 - Reading and Pasting Clipboard Text (`getStringAsync()`)

In the previous chapter, we learned how to copy text using:

```js
Clipboard.setStringAsync()
```

Now we'll learn how to **read text from the device clipboard** using:

```js
Clipboard.getStringAsync()
```

This is the API we'll use whenever our application needs to retrieve copied text.

---

# What Does `getStringAsync()` Do?

`getStringAsync()` reads the current text content from the system clipboard.

Syntax:

```js
const text =
  await Clipboard.getStringAsync();
```

For example, if the user previously copied:

```text
Hello React Native
```

then:

```js
const text =
  await Clipboard.getStringAsync();

console.log(text);
```

returns:

```text
Hello React Native
```

---

# Basic Flow

```text
Text Copied

↓

System Clipboard

↓

getStringAsync()

↓

React Native Application

↓

Display / Use Text
```

```js

```

```js
const pasteText = async () => {

    await Clipboard.getStringAsync();
```

```js
  console.log(text);

};
```

# What is a Clipboard URL?

A URL is a web address such as:

```text

```


```js
  await Clipboard.hasUrlAsync();
```

```js
  );

```

```js

  await Clipboard.getStringAsync();
```

You can then validate whether the returned string is a URL.

# Why Cleanup is Important

Suppose the user navigates:

```text
Home Screen

↓

Clipboard Screen

↓

Back
```

If you don't remove the listener, the listener could remain active longer than intended.

Always clean it up:

```js
return () => {

  subscription.remove();

};
```

This prevents unnecessary listeners and helps avoid memory/performance problems.
