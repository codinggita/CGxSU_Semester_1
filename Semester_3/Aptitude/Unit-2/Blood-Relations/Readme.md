# Blood Relations

## 1. The Trick

It's just like untangling "meet my sister's husband's brother" at a wedding — except now you're allowed to draw it.

```
Rule: Read one relationship at a time → draw it → move to the next
```

## 2. Your Toolkit

```
+  → Male
−  → Female
=  → Married to
↓  → Parent to Child
```

## 3. Relationship Cheat Sheet

```
Father's/Mother's father      → Grandfather
Father's/Mother's mother      → Grandmother
Father's/Mother's brother     → Uncle
Father's/Mother's sister      → Aunt
Brother's/Sister's son        → Nephew
Brother's/Sister's daughter   → Niece
Uncle's/Aunt's child          → Cousin
Spouse's brother              → Brother-in-law
Spouse's sister               → Sister-in-law
```

## 4. Generations = Floors of a Building

```
Floor 1 (Top): Grandparents
Floor 2: Parents, Uncles, Aunts
Floor 3: You, Siblings, Cousins
Floor 4: Children, Nephews, Nieces
```

## 5. The "Only Son/Daughter" Trap

```
"Son of my mother's only son" → if that son is my father, this is me
"Daughter of my grandfather's only son" → if that son is my father, this is my sister
```
