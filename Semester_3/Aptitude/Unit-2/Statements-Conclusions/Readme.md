# Statements and Conclusions

## 1. Basic Rule

A conclusion is valid only if it follows directly from the given statement(s), using pure logic. Do not use outside knowledge, assumptions, or personal opinion.

```
Valid conclusion = must follow strictly from the statement, not from general world knowledge
```

## 2. Types of Conclusions

```
Definitely true → follows directly from the statement
Definitely false → directly contradicts the statement
Cannot be determined → statement does not give enough information either way
```

## 3. Key Approach

```
Step 1: Read the statement only as given, treat it as 100% true, even if it sounds unusual
Step 2: Check each conclusion strictly against the statement
Step 3: Reject any conclusion that needs extra assumption or outside knowledge
```

## 4. Common Keywords and Their Meaning

```
"All" → every single member, no exceptions
"Some" → at least one, possibly all, but at least one for sure
"No" → none at all
"Only" → exclusively, nothing else qualifies
```

## 5. Cause and Effect Statements

Some questions give two statements and ask whether one is the cause, the effect, or both are independent causes/effects of a common factor.

```
If Statement 1 happened before Statement 2 and explains it → Statement 1 is the cause
If both statements are results of a separate common reason → independent causes
```

## 6. Assumptions in Statements

An assumption is something that is implied but not directly stated, and that must be true for the statement (such as an advertisement or announcement) to make sense.

```
A valid assumption is implicit in the statement, not an exaggerated or unrelated idea
```

## 7. Strong and Weak Arguments

Used when a statement is followed by arguments "for" or "against" a course of action.

```
Strong argument → directly relevant, significant, and addresses the main issue
Weak argument → irrelevant, minor, or based on assumption rather than fact
```
