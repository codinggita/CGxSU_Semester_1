# Time, Speed and Distance

## 1. Basic Formula

```
Speed = Distance / Time
Distance = Speed × Time
Time = Distance / Speed
```

## 2. Unit Conversion

```
To convert km/hr to m/s, multiply by 5/18
To convert m/s to km/hr, multiply by 18/5
```

## 3. Average Speed

Average speed depends on total distance and total time, not the simple average of speeds.

```
Average Speed = Total Distance / Total Time
```

**Equal distance covered at two speeds a and b:**

```
Average speed = 2ab / (a + b)
```

**Equal time intervals at two speeds a and b:**

```
Average speed = (a + b) / 2
```

## 4. Relative Speed

Used when two objects move and we need their speed with respect to each other.

```
Same direction: Relative speed = Difference of speeds
Opposite direction: Relative speed = Sum of speeds
```

## 5. Time Taken to Meet or Cross Each Other

```
Time = Distance between them / Relative speed
```

## 6. Trains Crossing Objects

**Crossing a stationary point or pole (train's own length only):**

```
Time = Length of train / Speed of train
```

**Crossing a platform or bridge (train's length + platform length):**

```
Time = (Length of train + Length of platform) / Speed of train
```

## 7. Two Trains Crossing Each Other

```
Time = (Sum of lengths of both trains) / Relative speed
```

Use sum of speeds if moving in opposite directions, and difference of speeds if moving in the same direction.

## 8. Boats and Streams

```
Downstream speed = Speed of boat + Speed of stream
Upstream speed = Speed of boat − Speed of stream
```

**Finding boat speed and stream speed from downstream and upstream speeds:**

```
Speed of boat = (Downstream + Upstream) / 2
Speed of stream = (Downstream − Upstream) / 2
```

## 9. Same Distance, Different Speeds (Change in Time)

If the same distance is covered at two different speeds, the change in time can be linked to the change in speed using the fact that distance stays constant.

```
Distance = Speed1 × Time1 = Speed2 × Time2
```

## 10. Races

In a race, the distance covered by different runners in the same time can be compared using their speed ratio.

```
If A gives B a head start of x metres in a race of d metres,
A covers d metres while B covers (d − x) metres in the same time
```
