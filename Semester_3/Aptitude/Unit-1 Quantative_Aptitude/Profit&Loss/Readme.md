# Profit and Loss

## 1. Basic Terms

CP (Cost Price) is the price at which an item is bought. SP (Selling Price) is the price at which it is sold.

```
Profit = SP − CP
Loss = CP − SP
```

## 2. Profit % and Loss %

Always calculated on the cost price, never on the selling price.

```
Profit % = (Profit / CP) × 100
Loss % = (Loss / CP) × 100
```

## 3. Finding SP from CP

```
SP = CP × (100 + Profit%) / 100
SP = CP × (100 − Loss%) / 100
```

## 4. Finding CP from SP

```
CP = SP × 100 / (100 + Profit%)
CP = SP × 100 / (100 − Loss%)
```

## 5. Marked Price and Discount

Discount is always calculated on the marked price (MP), not on the cost price.

```
Discount = MP − SP
Discount % = (Discount / MP) × 100
SP = MP × (100 − Discount%) / 100
```

## 6. Successive Discounts

Two discounts do not simply add up, since the second is applied on the already reduced price.

```
Equivalent single discount = a + b − (ab/100)
```

## 7. Connecting MP, CP and SP

```
MP → apply discount → SP → compare with CP → profit or loss
```

## 8. Selling Two Items at the Same Price

If two items are sold at the same price, one at x% profit and the other at x% loss, the result is always a loss.

```
Loss % = (x × x) / 100
```

## 9. Dishonest Shopkeeper (False Weight)

```
Gain % = [Error / (True Value − Error)] × 100
```

## 10. Profit Based on Number of Articles

```
If CP of x articles = SP of y articles
Profit % = [(x − y) / y] × 100
```

## 11. Marking Above Cost Price and Then Giving a Discount

```
MP = CP × (100 + Markup%) / 100
SP = MP × (100 − Discount%) / 100
```
