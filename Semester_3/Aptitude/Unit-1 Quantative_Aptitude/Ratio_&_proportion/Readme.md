
## 1. What is a Ratio

A ratio compares two quantities of the same kind by division. The ratio of a to b is written as a : b, meaning a/b.

Both quantities must be in the same unit, and the order matters — a:b is not the same as b:a.

## 2. Simplifying a Ratio

Divide both terms by their HCF, just like simplifying a fraction.

```
20 : 15 → HCF = 5 → 4 : 3
```

For ratios with fractions, take the LCM of the denominators and multiply through.

```
2/3 : 3/4 → LCM = 12 → 8 : 9
```

## 3. Dividing a Quantity in a Given Ratio

If N is divided in the ratio a : b:

```
First part = N × a/(a+b)
Second part = N × b/(a+b)
```

## 4. Comparing Ratios

Convert each ratio to a decimal and compare.

```
3:4 = 0.75
5:7 = 0.714
```

Since 0.75 > 0.714, 3:4 is greater.

## 5. Combining Two Ratios

To combine A:B and B:C into A:B:C, make the value of B equal in both ratios first (using their LCM), then combine.

```
A:B = 2:3 and B:C = 4:5
LCM of 3, 4 = 12
A:B = 8:12, B:C = 12:15
A:B:C = 8:12:15
```

## 6. Proportion

Two ratios that are equal form a proportion: a : b :: c : d, meaning a/b = c/d.

**Cross multiplication rule**

```
a : b = c : d  →  a × d = b × c
```

## 7. Continued Proportion

a, b, c are in continued proportion if a : b = b : c, which means:

```
b² = a × c
```

Here b is the mean proportional between a and c.

**Third proportional:** if a, b are given, find c using the same formula b² = a × c.

## 8. Direct Proportion

Two quantities increase or decrease together, keeping their ratio constant.

```
x1/y1 = x2/y2
```

## 9. Inverse Proportion

One quantity increases while the other decreases, keeping their product constant.

```
x1 × y1 = x2 × y2
```

**How to tell direct from inverse:** ask whether increasing one quantity increases or decreases the other. Both increase/decrease together → direct. One up, other down → inverse.

## 10. Ratio and Percentage Together

If two quantities are in ratio a:b:

```
First quantity % of total = [a/(a+b)] × 100
Second quantity % of total = [b/(a+b)] × 100
```
