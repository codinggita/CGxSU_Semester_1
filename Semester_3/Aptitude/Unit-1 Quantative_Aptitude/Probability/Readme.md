# Basic Probability

## 1. Basic Formula

```
Probability of an event = Number of favourable outcomes / Total number of possible outcomes
```

Probability always lies between 0 and 1.

```
0 ≤ P(event) ≤ 1
```

## 2. Sample Space

The sample space is the set of all possible outcomes of an experiment.

```
Example setup: Tossing a coin → Sample space = {Head, Tail}
Rolling a die → Sample space = {1, 2, 3, 4, 5, 6}
```

## 3. Complementary Event

The probability that an event does NOT happen is 1 minus the probability that it does happen.

```
P(not A) = 1 − P(A)
```

## 4. Addition Rule (Either Event Happens)

**For mutually exclusive events (cannot happen at the same time):**

```
P(A or B) = P(A) + P(B)
```

**For events that can happen together:**

```
P(A or B) = P(A) + P(B) − P(A and B)
```

## 5. Multiplication Rule (Both Events Happen)

**For independent events (one does not affect the other):**

```
P(A and B) = P(A) × P(B)
```

## 6. Cards (Standard Deck)

```
Total cards = 52
Red cards = 26, Black cards = 26
4 suits: Spades, Hearts, Diamonds, Clubs (13 cards each)
Face cards = 12 (Jack, Queen, King of each suit)
```

## 7. Dice

```
A single die has 6 faces: 1, 2, 3, 4, 5, 6
Two dice thrown together give 36 total outcomes (6 × 6)
```

## 8. Coins

```
One coin tossed → 2 outcomes
Two coins tossed together → 4 outcomes
n coins tossed together → 2ⁿ outcomes
```

## 9. Combinations in Probability (Choosing Items)

When probability involves choosing a group of items (like balls from a bag), the number of ways to choose is found using combinations.

```
Number of ways to choose r items from n items = n! / (r! × (n−r)!)

Probability = (Favourable combinations) / (Total combinations)
```

## 10. Conditional Probability

The probability of an event happening, given that another event has already happened.

```
P(A given B) = P(A and B) / P(B)
```
