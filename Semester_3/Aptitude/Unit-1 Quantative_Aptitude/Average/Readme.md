## 1. What is an Average

Average means finding one single value that represents a group of numbers.

## 2. Basic Formula

```
Average = Sum of all values / Number of values
```

## 3. Finding the Total from the Average

If we already know the average, we can find the total by flipping the formula.

```
Total = Average × Number of values
```

## 4. Finding a Missing Value

If we know the average of a group and all values except one, we can find the missing value.

Example: Average of 5 numbers is 24. Four numbers are 20, 22, 25, 28. Find the fifth.

```
Total = 24 × 5 = 120
Sum of known 4 numbers = 20+22+25+28 = 95
Missing number = 120 − 95 = 25
```

## 5. Adding a New Value

When a new value joins the group, both the total and the number of values increase.

Example: Average of 10 students is 60. A new student scores 80. Find the new average.

```
Old total = 10 × 60 = 600
New total = 600 + 80 = 680
New average = 680/11 = 61.8 (approx)
```

## 6. Removing a Value

When a value is removed, both the total and the number of values decrease.

Example: Average of 8 numbers is 25. One number, 32, is removed. Find the new average.

```
Old total = 25 × 8 = 200
New total = 200 − 32 = 168
New average = 168/7 = 24
```

## 7. Replacing a Value

When one value is replaced by another, the number of values stays the same, only the total changes.

```
New Total = Old Total − Old Value + New Value
```

## 8. When Every Value Changes by the Same Amount

If every single value in a group goes up or down by the same amount, the average also changes by that same amount.

Example: Average marks of a class is 65. Every student gets 5 extra marks.

```
New average = 65 + 5 = 70
```

## 9. Combining Two Groups (Combined Average)

When two groups are joined together, we cannot simply average their two averages — we must use the actual totals.

```
Combined Average = (n1×Average1 + n2×Average2) / (n1 + n2)
```

## 10. Weighted Average

Used when different values carry different importance (called "weight").

```
Weighted Average = (x1×w1 + x2×w2 + ...) / (w1 + w2 + ...)
```

## 11. Average Speed

```
Average Speed = Total Distance / Total Time
```

## 12. Average of Equally Spaced (Consecutive) Numbers

If numbers increase by the same gap each time (like 11,12,13,14,15), you don't need to add everything — just use:

```
Average = (First number + Last number) / 2
```
