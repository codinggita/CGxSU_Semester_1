# Time and Work

## 1. One Day's Work

If a person finishes a work in n days, their 1 day's work is:

```
1 day's work = 1 / n
Days needed to finish work = 1 / (1 day's work)
```

## 2. Work Done in Several Days

```
Work done in x days = x × (1 day's work)
```

## 3. Two or More People Working Together

```
Combined 1 day's work = 1/A + 1/B + ...
Days to finish work together = 1 / (Combined 1 day's work)
```

## 4. Shortcut for Two People Working Together

If A alone takes 'a' days and B alone takes 'b' days:

```
Days together = (a × b) / (a + b)
```

## 5. Efficiency and Time

A faster (more efficient) person takes fewer days. Efficiency and time are inversely related.

```
Efficiency ∝ 1 / Time taken
If Efficiency A : Efficiency B = m : n, then Time A : Time B = n : m
```

## 6. Work and Wages

Payment is split in the same ratio as the work each person did (their efficiency).

```
Wage ratio = Efficiency ratio = 1/(Days taken by each person)
```

## 7. Men, Days and Work (Group Comparison)

```
M1 × D1 / W1 = M2 × D2 / W2
M1 × D1 × H1 / W1 = M2 × D2 × H2 / W2  (if hours per day are given)
```

## 8. People Joining or Leaving Midway

Split the work into stages and add up the work done in each stage.

```
Work done in a stage = (Workers × Days worked) / (Days needed by 1 worker alone)
```

## 9. Pipes and Cisterns

Filling is positive work, draining is negative work.

```
Inlet pipe's 1 hour work = + 1/n
Outlet pipe's 1 hour work = − 1/n
```

## 10. Filling and Draining Together

```
Net 1 hour work = (Total filling work) − (Total draining work)
Time to fill/empty = 1 / (Net 1 hour work)
```

## 11. Alternating Work Pattern

```
Work done in one round = Sum of work by each person/pipe in their turn
Number of rounds needed = Total work / Work done per round
```
