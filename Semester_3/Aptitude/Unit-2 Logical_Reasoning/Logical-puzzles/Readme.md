# Basic Logical Puzzles

## 1. What are Logical Puzzles

These questions give a set of conditions about people, objects, or positions, and ask you to arrange or match them correctly using only logical deduction.

## 2. General Approach

```
Step 1: List out all people/objects involved
Step 2: Convert each condition into a short note or symbol
Step 3: Start with the most definite (fixed) condition first
Step 4: Use elimination for the remaining open conditions
Step 5: Cross-check the final arrangement against every condition given
```

## 3. Linear Arrangement

People or objects are arranged in a single row or line, facing a particular direction.

```
Keywords: "immediately left/right of", "to the left/right of", "between", "at the ends"
Draw a single row of blanks and fill step by step based on the conditions
```

## 4. Circular Arrangement

People or objects are arranged around a circle, either facing the center or facing outward.

```
If facing the center: left hand side and right hand side are reversed compared to normal
If facing outward: left/right directions match the normal sense
```

## 5. Double Row Arrangement

Two rows of people face each other (or face the same direction), and relationships involve both rows.

```
Keywords: "faces", "opposite to"
Draw two parallel rows and match positions directly across from each other
```

## 6. Floor-Based Puzzles

People or items are placed on different floors of a building, usually numbered from bottom to top or top to bottom.

```
"Above", "below", "immediately above/below" define the floor order directly
Draw floors as a vertical list and fill based on fixed clues first
```

## 7. Matching-Type Puzzles (Grid Puzzles)

Different attributes (such as name, subject, color, day) must be matched to each person, using a grid.

```
Step 1: Make a grid with people as rows and attributes as columns
Step 2: Mark "yes" or "no" based on each clue
Step 3: Use elimination — once one match is confirmed, mark all other combinations in that row/column as "no"
```

## 8. Common Clue Keywords

```
"Immediately next to" → directly adjacent, no gap
"Not adjacent to" → cannot be placed next to
"Exactly between" → one person/object exactly in the middle of two others
"More than / less than" → used for ranking or counting positions
```
