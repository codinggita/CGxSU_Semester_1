# Syllogisms

## 1. What is a Syllogism

A syllogism gives two or more statements (called premises) and asks which conclusions logically follow from them, using only the information given.

## 2. Four Types of Statements

```
All A are B     → Universal Positive
No A are B      → Universal Negative
Some A are B    → Particular Positive
Some A are not B → Particular Negative
```

## 3. Basic Rule for Combining Statements

```
Two particular statements (Some / Some not) together give no definite conclusion
At least one premise must be universal (All / No) to get a definite conclusion
```

## 4. Conversion Rules (What Can Be Concluded from a Single Statement)

```
"All A are B" → "Some B are A" (valid), but "All B are A" is NOT valid
"No A are B" → "No B are A" (valid)
"Some A are B" → "Some B are A" (valid)
"Some A are not B" → cannot be converted
```

## 5. Venn Diagram Approach

```
Step 1: Draw a circle for each group mentioned in the statements
Step 2: Based on "All / No / Some / Some not", draw overlapping, separate, or contained circles
Step 3: Check each conclusion by seeing if it holds true in every possible diagram that fits the statements
```

## 6. Either-Or Case

Used when two conclusions individually seem false, but one of them must definitely be true.

```
Either-or applies when:
1. Both conclusions are false individually when checked alone
2. The subject and predicate are the same in both conclusions
3. Combining "some" and "all" or "some" and "no" covers every possibility
```

## 7. Possibility Cases

Some questions ask what is "possible" rather than what "definitely follows."

```
A possibility conclusion is acceptable if there exists at least one valid diagram
where the conclusion could be true, even if it is not always true
```
