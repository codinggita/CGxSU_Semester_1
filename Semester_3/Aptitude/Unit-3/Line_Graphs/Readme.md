# Line Graphs

## 1. What is a Line Graph

A line graph shows how a quantity changes over time (years, months, days). Points are joined by a line, so the trend (rise or fall) is easy to see.

```
X-axis → usually time (year, month)
Y-axis → the quantity (sales, production, profit, etc.)
```

## 2. How to Read It

```
Step 1: Read the title and axis labels
Step 2: Check the scale and units on the Y-axis
Step 3: Read the value of each point against the Y-axis
```

## 3. Trend Terms

```
Line going up → increase
Line going down → decrease
Flat line → no change
Steepest part of the line → highest change (rise or fall)
```

## 4. Absolute Change

```
Change = Value in later year − Value in earlier year
```

## 5. Percentage Change

```
% Change = [(Later value − Earlier value) / Earlier value] × 100
```

## 6. Average Over a Period

```
Average = Sum of all values in the period / Number of years
```

## 7. Year-wise Growth

```
Growth in a year = Value of that year − Value of previous year
Growth % in a year = (Growth / Previous year value) × 100
```

## 8. Two Lines on One Graph

When two lines are drawn (for example, two companies), compare them point by point.

```
Difference at a point = Value of line 1 − Value of line 2
Point where the lines cross → both values are equal at that time
```

## 9. Ratio of Two Lines

```
Ratio at a given year = Value of line 1 : Value of line 2
```
