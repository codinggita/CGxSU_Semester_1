# Pie Charts

## 1. What is a Pie Chart

A pie chart is a circle divided into slices. Each slice shows the share of one category out of the total. The whole circle is 100% and 360°.

```
Whole circle = 100% = 360°
```

## 2. Basic Conversions

```
1% = 3.6°
Central angle = (Value / Total) × 360°
Percentage = (Angle / 360) × 100
```

## 3. Finding Value from Percentage or Angle

```
Value = (Percentage / 100) × Total
Value = (Angle / 360) × Total
```

## 4. Finding the Total

```
Total = Value / (Percentage/100)
Total = Value × 360 / Angle
```

## 5. Comparing Two Slices

```
Ratio of two categories = Angle 1 : Angle 2 = Percentage 1 : Percentage 2
```

## 6. Difference Between Two Categories

```
Difference in value = (Percentage 1 − Percentage 2) / 100 × Total
```

## 7. Two Pie Charts Together

When two pie charts (for example, two different years or two different companies) are given with different totals, compare actual values, not percentages.

```
Actual value = (Percentage / 100) × Total of that chart
```

## 8. Common Angle-Percentage Values

```
90° = 25%
72° = 20%
36° = 10%
18° = 5%
180° = 50%
120° = 33.33%
```
