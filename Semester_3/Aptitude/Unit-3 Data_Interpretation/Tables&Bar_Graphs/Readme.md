# Tables and Bar Graphs

## 1. How to Read a Table

A table shows data in rows and columns. Always check the title, units (Rs., kg, thousands, lakhs) and column headings before solving.

```
Row → one item (year, company, student, etc.)
Column → one category of data (sales, profit, marks, etc.)
```

## 2. Total and Average

```
Total = Sum of all required values
Average = Total / Number of values
```

## 3. Percentage of a Value

```
Percentage = (Part / Whole) × 100
```

## 4. Percentage Increase and Decrease

```
% Change = [(New value − Old value) / Old value] × 100
```

A positive result means increase, a negative result means decrease.

## 5. Ratio Between Two Values

```
Ratio = Value 1 : Value 2
```

## 6. Reading a Bar Graph

A bar graph shows values as bars. Height (or length) of the bar gives the value.

```
Step 1: Read the title and the axis labels (what is on X-axis, what is on Y-axis)
Step 2: Check the scale (what does one division represent)
Step 3: Read the bar height against the Y-axis carefully
```

## 7. Types of Bar Graphs

```
Simple bar graph → one bar for each category
Double/Multiple bar graph → two or more bars per category (for comparison)
Stacked bar graph → one bar divided into parts, total height = sum of all parts
```

## 8. Common Calculations in Bar Graph Questions

```
Difference = Larger value − Smaller value
Average over years = Sum of bar values / Number of years
Combined total = Add the bars of the same category
```
