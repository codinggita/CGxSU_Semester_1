# Basic Data Comparison Techniques

## 1. Why Compare

Most data interpretation questions ask which item is higher, by how much, or by what percentage. The right method depends on what is being compared.

## 2. Absolute Difference

```
Difference = Larger value − Smaller value
```

## 3. Percentage Comparison

When one value is compared to another, the base is always the value after "than" or "of".

```
A is what % of B = (A / B) × 100
A is what % more than B = [(A − B) / B] × 100
A is what % less than B = [(B − A) / B] × 100
```

## 4. Percentage Point vs Percent Change

```
Percentage point difference = Percentage 1 − Percentage 2
Percent change = [(New % − Old %) / Old %] × 100
```

These two are not the same. Going from 20% to 25% is a 5 percentage point rise, but a 25% increase.

## 5. Ratio Comparison

```
Ratio of A to B = A : B
Compare two ratios by converting each to a fraction or decimal
```

## 6. Average Comparison

```
Average = Total / Number of values
Higher average → better performance (when the number of items is the same or averages are compared directly)
```

## 7. Growth Comparison

```
Growth % = [(Final − Initial) / Initial] × 100
Higher growth % → faster growth, even if the actual increase is smaller
```

## 8. Average Annual Growth (Simple)

```
Average annual growth = Total growth / Number of years
```

## 9. Share Comparison

```
Share of a category = (Category value / Total) × 100
Contribution to total change = Change in category / Total change
```

## 10. Quick Comparison Without Full Calculation

```
Compare fractions by cross multiplication: a/b vs c/d → compare a × d with b × c
Compare using approximation (round to nearest convenient number) when options are far apart
```
