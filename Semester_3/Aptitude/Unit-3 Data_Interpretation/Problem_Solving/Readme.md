# Problem-Solving Strategies for Timed Tests

## 1. Before Solving

```
Step 1: Read the title, headings, units and scale first
Step 2: Check whether values are in thousands, lakhs, crores, % or actual numbers
Step 3: Read the question fully before touching the data
```

## 2. Order of Attempting

```
Attempt easy direct-read questions first
Attempt calculation-heavy questions after
Leave very lengthy questions for the end
```

## 3. Use Approximation

When options are far apart, exact calculation is not needed.

```
Round numbers to the nearest convenient value (for example, 49.8 ≈ 50)
Compare the approximate answer with the options
```

## 4. Use Option Elimination

```
Check the units and range of the answer
Remove options that are clearly too high or too low
```

## 5. Use Fraction–Percentage Shortcuts

```
1/2 = 50%, 1/3 = 33.33%, 1/4 = 25%, 1/5 = 20%
1/6 = 16.67%, 1/8 = 12.5%, 1/10 = 10%
```

## 6. Avoid Unnecessary Calculation

```
If only a comparison is asked, compare directly instead of finding exact values
If only the ratio is asked, do not convert to actual values
```

## 7. Common Traps

```
Wrong base in percentage questions
Ignoring units (thousands vs lakhs)
Mixing percentage points with percent change
Reading the wrong bar or point on the graph
Using the wrong year or category
```

## 8. Time Management

```
Aim for roughly 1 to 1.5 minutes per question
If a question takes too long, mark it and move on
Keep a few minutes at the end to recheck marked questions
```

## 9. Last Check

```
Re-read what the question asked (value, percentage, ratio, difference)
Confirm the unit of the answer matches the options
```
